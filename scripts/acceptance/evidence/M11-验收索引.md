## 关键实证

1. **真实提交闭环**（runtime #4 段）：CDP 网络域捕获 `POST /api/data/1` → 200，
   载荷 `{"title":"CDP-<唯一戳>","amount":88}`；DB 精确核对行 `1|2|<戳>|88`
   （租户 1 / 创建者 accept_user / 金额 88 / 唯一戳）；记录 ID 可反查。
2. **登出会话失效**：logout 200 → `/api/me` 401 → refresh 401 → 页面强制 reload 后
   SessionExpired 占位（`登录已失效`）。修复实证：登出前旧 at 访问 /api/me 200，
   登出后 401（`CookieSessionIT.logoutRevokesAccessTokenToo` 12/12 绿）。
3. **缓存隔离**：ETag v11→v12 轮换（发布后旧 ETag 200 全量）；草稿保存后正式仍 304
   且内容不含草稿改动；预览 token 限页（pageId 999 → 404）；预览自我吊销闭环
   （吊销后读取 401 PREVIEW_SESSION_REVOKED）。
4. **权限与隔离**：普通成员成员清单/发公告/公告历史全 403；租户 2 应用列表为空；
   伪造 X-Tenant-Id → 403 TENANT_MISMATCH（审计触发）。
5. **凭证协议**：全部登录响应 Cookie 三件套（schema_at/rt/csrf）+ 响应体零凭证。

## 限制与说明

- **backend-it 探活**：verify.ps1 在 Windows 侧探 127.0.0.1:5432 探不到 WSL PG
  （Windows→WSL 网络半失效环境已知项）——集成测试本体在 WSL 内全绿。
- **会话过期占位断言依赖强制 reload**：同 hash 路由 `Page.navigate` 不触发重载，
  验收脚本用 `Page.reload` 模拟用户刷新（真实用户登出后刷新/重进同效）。
- **真实点击与 CDP evaluate 差异**：evaluate 内合成 click 不被 React 分发（React 18
  事件委托边界），验收一律用 CDP Input 域真实鼠标事件——真实用户操作无此差异。
- **资产发布修复（G-04）**：`scripts/deploy.py` 三应用资产统一合并 `web/assets/`
  （同路径同内容复用/不同内容构建失败）+ 入口引用完整性校验。隔离目录测试通过
  （`.session_tmps/.../test-asset-merge.py`）；**尚未对生产执行部署**（按验收纪律
  在隔离目录验证，不切换生产版本——生产发布走 M16 上线门禁）。
