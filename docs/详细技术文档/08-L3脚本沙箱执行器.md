# 详细技术文档 08 · L3 脚本沙箱执行器（script-executor）

> 上游：《技术方案-后端(Java).md》v0.2 §9.1；PRD §7.3（L3 决策：Phase 3 企业版默认关闭）
> 本文定位：实现级技术设计——部署形态、六道闸门、序列化边界、版本灰度
> 服务：`script-executor`（独立部署，与主集群网络隔离）

---

## 1. 部署形态

```
主应用集群（K8s namespace: app）
   │ 仅内网 RPC（gRPC，mTLS 双向认证）
   ▼
script-executor（独立 namespace: sandbox，NetworkPolicy: 默认拒绝出网）
   ├─ Pod 模板 A：GraalVM Polyglot 受限 Context（JS 单语言）
   └─ Pod 模板 B（可选升级）：gVisor 隔离运行时 + V8（更严场景）
```

- **绝不在主应用进程 eval 客户代码**（Nashorn 已死、Rhino 无隔离，均不可选）；
- 执行器无状态：脚本内容随请求携带（或按 scriptId+version 从主库拉取），执行结果即返；
- 主应用与执行器间流量走 mTLS，sandbox namespace 的 NetworkPolicy 默认全禁出网（白名单按连接器配置逐条开）。

## 2. 执行接口

```java
public interface ScriptExecutor {
    ExecResult execute(ExecRequest req);
}

class ExecRequest {
    Long tenantId;
    String scriptId; Integer scriptVersion;   // 或直接传 sourceCode（调试模式）
    String entry;                             // 入口函数名，如 "handler"
    Map<String, Object> input;                // 流程节点/触发器上下文（JSON）
    ExecContext ctx;                          // 租户/用户/角色——数据访问继承此权限
    Duration timeout = Duration.ofSeconds(5);
    int memoryLimitMb = 256;
    int cpuTimeMs = 2000;                     // CPU 时间与 wall-clock 分开限制
}

class ExecResult {
    boolean success; JsonNode output;
    long durationMs; String errorStack;       // 沙箱内捕获的异常堆栈（序列化后返回）
    String traceId;
}
```

## 3. 六道闸门实现

| 闸门 | 技术落地 |
|---|---|
| ① 进程隔离 | GraalVM Context 构建参数：`allowHostAccess(false)`、`allowIO(false)`、`allowCreateProcess(false)`、`allowNativeAccess(false)`、`allowEnvironmentAccess(false)`；HostClass 暴露白名单为空 |
| ② 资源上限 | wall-clock：Future.cancel + 线程中断（沙箱引擎 `Context.interrupt()`）；内存：`ResourceLimit` 或 Pod cgroup 256MB 兜底；CPU：`engine.setResourceLimits`；出网：NetworkPolicy 默认拒绝 |
| ③ 数据访问 | 只注入 `dataEngineClient`（内部 RPC client），调用时**透传 ExecContext**（租户+用户+角色）→ data-engine SQL 构建层二次校验行级/字段权限——**不信任脚本层，权限在 SQL 层兜底** |
| ④ 可观测 | 每次执行落 `script_exec_log(scriptId, version, traceId, duration, status, errorStack)`；客户控制台可查（脱敏）；接入 SkyWalking trace 贯穿主应用→沙箱 |
| ⑤ 版本灰度 | 脚本表 version + status（DRAFT/PUBLISHED/CANARY）；灰度按 appId 白名单或流量百分比路由；一键回滚 = 切 PUBLISHED 指针 |
| ⑥ 配额计费 | Redis 令牌桶：单租户并发上限（如 5）+ QPS 上限；执行次数投递计量事件（计入 flow.exec 类口径） |

## 4. 序列化边界（GraalVM 沙箱最易踩的坑）

```
入站：Java → JS
  input 与 ctx 必须【深拷贝 + JSON 序列化】后注入
  —— 绝不能把 Java 对象引用直接塞进 ContextBindings
  —— 否则脚本拿到 Proxy/HostObject 引用，可反射逃逸（Class.getClassLoader() → 任意执行）

出站：JS → Java
  返回值仅接受【JSON 可表达类型】：number/string/boolean/array/object/null
  函数/Proxy/Class 实例一律拒绝（抛序列化错误）
  —— 用 Value.toJsonString 走 JSON 边界，不走 Value.asHostObject
```

## 5. 执行流程

```
execute(req):
  ① 配额预检（令牌桶，租户并发 + QPS）
  ② 脚本获取：按 scriptId+version 拉已发布源码（或调试模式直传，仅沙箱预览环境）
  ③ 构建 Context：
     - 引擎参数按 §3 闸门①
     - 绑定注入：dataEngineClient（RPC stub）、logger（落日志表）、constants（白名单工具函数）
  ④ 深拷贝 input/ctx → JSON → 注入绑定
  ⑤ 执行 entry(input, ctx)，限时监控线程启动
  ⑥ 超时/内存超限：Context.interrupt() → 返回 TIMEOUT/OOM 错误（栈不返回给客户，记录内部）
  ⑦ 结果 JSON 边界校验 → 返回
  ⑧ 落 exec_log + 计量事件 + trace 上报
```

## 6. 脚本版本状态机

```
DRAFT（编辑中，仅测试台可跑）
  → 提交审核 → PUBLISHED（正式版）
  → 灰度切换 → CANARY（10% 流量验证）→ 全量 PUBLISHED
回滚：PUBLISHED 指针切回历史 version，秒级生效
审核：线上改动（PUBLISHED/CANARY 状态变更）需审核记录
```

## 7. 开通与默认关闭

- 开通条件：企业版套餐 + 书面确认责任边界（脚本正确性与安全客户自担，平台保证执行环境隔离与版本兼容）；
- 平台侧开关（租户级 feature flag）默认 OFF；开启后脚本入口才在设计器/流程编排中出现；
- 不做的：Python/Java 多语言（先 JS 单语言）、npm 依赖（仅平台 SDK + 白名单库）、脚本跨租户共享。

## 8. 单元测试硬性要求

- [ ] 逃逸样本：`input.constructor.constructor('return Process')` 等 20+ 条逃逸 payload 全部被拦（JSON 边界 + Context 参数双重保证）
- [ ] 资源：死循环 5s 被硬中断；大数组分配触发内存上限
- [ ] 权限：无权限用户跑脚本，dataEngineClient 查询被行级过滤（用越权用例验证）
- [ ] 序列化：Java 对象引用注入尝试被拒；返回函数类型被拒
- [ ] 灰度：CANARY 流量按百分比路由正确；回滚秒级
- [ ] 并发上限：超并发请求被令牌桶拒绝且返回明确错误码

## 附录 A · 对外接口契约

> 前端消费方：L3 脚本管理台（admin-console，企业版默认关闭）、流程编排脚本节点属性面板（前端文档 10 §2.1）、执行日志面板。
> 注意：L3 是**后端脚本**，与前端 L2 钩子（前端文档 08FE）完全隔离；本节接口仅企业版开通后可见。

### A.1 脚本管理（状态机见 §6）

| 方法 | 路径 | 请求 | 响应 |
|---|---|---|---|
| POST | `/api/scripts` | `{name, sourceCode, entry}` | `{scriptId, version:1, status:'DRAFT'}` |
| PUT | `/api/scripts/{id}/source` | `{sourceCode, entry}` | `{version, compileErrors?}`（语法预检在保存时执行，红线扫描同 L2 redlines.json 后端侧） |
| POST | `/api/scripts/{id}/publish` | — | `{version, status:'PUBLISHED'}`（需审核，灰度配置见 A.2） |
| POST | `/api/scripts/{id}/rollback` | `{targetVersion}` | `{version}`（秒级生效） |
| GET | `/api/scripts/{id}/versions` | — | `{list:[{version, status, publishedAt, grayPercent}]}` |

### A.2 灰度控制

| 方法 | 路径 | 请求 | 响应 |
|---|---|---|---|
| POST | `/api/scripts/{id}/canary` | `{percent:10}` | `{status:'CANARY', percent}`（10% 流量走新版本） |
| POST | `/api/scripts/{id}/promote` | — | `{status:'PUBLISHED', percent:100}`（全量） |

### A.3 手动执行（调试）与日志

| 方法 | 路径 | 请求/说明 | 响应 |
|---|---|---|---|
| POST | `/api/scripts/{id}/execute` | `{input(JSON), ctx:{userId}}`（调试模式：不入计量、traceId 透传） | `{success, output, durationMs, errorStack?, traceId}`（结构同 §2 ExecResult） |
| GET | `/api/scripts/{id}/executions?page=&size=&status=` | 执行历史 | `{list:[{execId, status, durationMs, errorStack?, callerType, occurredAt}]}`（script_exec_log 面板数据源） |

### A.4 错误码（本域）

| code | HTTP | 场景 |
|---|---|---|
| `SCRIPT_TIMEOUT` | 504 | 5s 硬超时（沙箱内中断） |
| `SCRIPT_MEMORY_EXCEEDED` | 500 | 256MB 上限 |
| `SCRIPT_COMPILE_ERROR` | 422 | 语法/红线预检失败（含行号） |
| `CONCURRENCY_LIMIT` | 429 | 租户并发令牌桶拒绝 |
| `L3_NOT_ENABLED` | 403 | 企业版未开通（默认关闭的产品语义） |

### 前端对接要点

- 脚本节点属性面板复用 Monaco + 平台 SDK d.ts（与 L2 测试台同源编辑器组件，前端文档 08FE §6）；
- 灰度滑杆（10%→全量）+ 一键回滚交互消费 A.2 接口；`errorStack` 行号映射回源码需 sourcemap（构建服务产物约定同文档 04 §2.3）。
