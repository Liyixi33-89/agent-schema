## 更新原则

1. **只有实际执行并产出结构化结果的项才改判定**——目录或脚本存在不改判定。
2. **如实登记未达标**：150VU FAIL 与 250VU 不可达不因复验而消失，处置选项呈报用户裁决。
3. **架构性豁免显式声明**：TC-FT-03（下游超时）/TC-UP-01（滚动升级）在单实例架构下无注入点，判 N/A 并声明 Phase 2 补演练——不冒充通过。
4. **执行≠批准**：本轮全部产出不构成独立审查与上线批准，G1-G7 汇总与人工批准仍按 §8 门禁执行。
