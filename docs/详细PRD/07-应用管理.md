# 详细PRD 07 · 应用管理

> 上游文档：《PRD-低代码平台产品规划》v0.2 §3.7
> 本文定位：功能操作级 PRD——入口、界面、操作步骤、配置项、规则与反馈
> 交付阶段：Phase 1（应用 CRUD + 成员 + 导航 + 发布），Phase 2（模板中心 + 导出导入 + 跨应用引用），Phase 3（应用市场生态）

---

## 1. 模块概述

### 1.1 是什么

应用是租户内的一等组织单元：模型、页面、流程、连接器引用都归属应用；应用有自己的成员与角色、导航壳与主题、独立发布节奏。**应用的存在让"一个大租户做 N 个业务系统"不互相污染。**

### 1.2 服务角色

| 角色 | 在本模块做什么 |
|---|---|
| 租户管理员 | 创建应用、任命应用管理员、归档应用 |
| 应用管理员 | 管应用成员/导航/发布/模板安装 |
| 使用者 | 从工作台进入应用 |

### 1.3 入口

- 租户工作台首页 = 应用卡片墙（Logo/名称/描述/我的角色）+「创建应用」
- 应用内设置：「成员」「导航」「主题」「发布记录」四个页签

## 2. 页面与操作明细

### 2.1 应用创建与设置

| 操作 | 触发 | 系统行为 |
|---|---|---|
| 创建应用 | 工作台「创建应用」 | 弹窗：名称/图标/描述/来源（空白 / 从模板，P2）→ 创建后创建者成为应用管理员 |
| 改名/图标 | 设置 → 基本信息 | 即时生效 |
| 归档 | 「···」→ 归档（P2） | 所有资源只读保留、可恢复；工作台卡片隐藏 |
| 彻底删除 | 管理员审批（P2） | 走审批 + 数据保留期说明，与逻辑删除原则一致 |

**应用结构**：

```
应用（App）
├── 模型集合（强归属本应用）
├── 页面集合 + 导航菜单树
├── 流程集合
├── 连接器实例引用（连接器定义在租户级，应用级引用+授权）
├── 成员与角色（应用级角色覆盖租户默认角色权限）
└── 主题配置（Logo/主色/登录页背景）
```

- **归属规则**：模型/页面/流程强归属单应用（防"谁的模型"扯皮）；连接器、物料为租户级共享（密钥不该按应用重复配）。

### 2.2 应用成员与角色

**界面**：应用设置 →「成员」→ 成员列表（姓名/应用角色/加入时间）+「添加成员」。

| 应用角色 | 能力 |
|---|---|
| 应用管理员 | 成员管理、发布/回滚、删除应用级资源 |
| 开发者 | 建模、设计页面/流程（不能发布、不能管成员） |
| 使用者 | 按页面权限访问运行时 |

- 租户管理员天然是所有应用管理员；应用成员必须先存在于租户组织；
- **席位判定**：拥有任一应用「开发者及以上」角色 = 设计者席位（活跃口径见 §09）。

### 2.3 导航配置

**界面**：应用设置 →「导航」→ 菜单树编辑器。

- 节点类型：页面（单选，带权限过滤）/ 分组 / 外链；
- 拖拽排序与层级调整；
- 菜单可见性 = 节点权限 ∩ 目标页面权限；运行时导航壳按当前用户过滤渲染（无权限菜单不出现）。

### 2.4 应用发布与回滚

发布/回滚机制继承 §06：应用级「发布」按钮 = 把应用全部 draft 页面生成发布快照；发布记录按应用归档（版本号/操作人/变更页面清单）。

### 2.5 模板中心（P2）

**模板 = 应用完整快照**（模型 Schema + 页面 Schema + 流程 Schema + 示例数据开关）。

**安装流程**：选模板 → 起应用名 → 依赖完整性检查（物料/连接器是否可用）→ 可选导入示例数据（**显式勾选**才导入）→ 完成。

- 安装后的资源**完全可编辑**（一次性拷贝，与模板市场解耦）；
- 模板升级**不回写**已装应用（安装完成页明确告知）；
- 官方首批模板：报销审批、请假考勤、设备报修、进销存、CRM 线索管理（每个 = 3-6 模型 + 8-15 页面 + 1-3 流程）。

### 2.6 应用导出/导入（P2）

- 导出：生成 `.schema-app` 包（JSON 清单 + 版本声明 + 资源集合），**不含业务数据与密钥**；
- 导入：同租户内复制应用；跨租户迁移 P3 计划内；资源 key 冲突时自动重命名并列出映射表。

### 2.7 跨应用模型引用（P2）

- 应用 A 的页面可引用应用 B 的模型（**只读引用**，建模编辑仍归 B 应用开发者）；
- 引用建立需 B 应用管理员**授权**（防数据边界失控）；
- 被引用模型发生 DELETED 变更时，A 应用页面收到影响面提示（跨应用影响面分析）。

## 3. 业务规则汇总

| # | 规则 | 来源 |
|---|---|---|
| R1 | 模型/页面/流程强归属单应用；连接器/物料租户级共享 | §2.1 |
| R2 | 归档代替删除（只读保留可恢复） | §2.1 |
| R3 | 模板安装为一次性拷贝，升级不回写 | §2.5 |
| R4 | 导出包不含业务数据与密钥 | §2.6 |
| R5 | 跨应用引用必须目标应用管理员授权且只读 | §2.7 |
| R6 | 应用管理员角色不占席位；开发者及以上才占 | §2.2 |

---

## 4. 权限点

| 权限点 | 说明 |
|---|---|
| 应用访问 | 工作台可见 + 运行时进入 |
| 应用管理 | 成员/导航/主题/发布/归档全套 |
| 应用创建 | 租户管理员（可配置开放给指定角色） |

---

## 5. 验收标准

- [ ] 创建应用 → 加成员（开发者/使用者）→ 配导航 → 发布，全流程 ≤ 10 分钟
- [ ] 使用者看不到无权限菜单；直链访问无权限页面返回 403
- [ ] 模板安装生成完整可运行应用；示例数据可跳过；安装后可任意修改
- [ ] 应用导出再导入后，页面/流程/模型定义一致（Schema diff 为空）
- [ ] 跨应用引用未授权时不可选对方模型；授权后对方模型删字段时收到影响面警示
- [ ] 归档应用后资源只读，恢复后可继续编辑

---

## 6. 边界与不做的事

- 应用间数据路由（A 应用页面直接写 B 应用模型数据）—— 引用只读
- 多应用统一搜索入口 —— P3
- 模板付费分成/版本升级推送 —— P3（应用市场阶段）
- 应用级独立域名 —— P3（跟随私有化交付节奏）
