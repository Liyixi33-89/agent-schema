# 详细PRD 02 · 页面设计器

> 上游文档：《PRD-低代码平台产品规划》v0.2 §3.2；渲染决策 §6.2（双轨渲染）
> 本文定位：功能操作级 PRD——入口、界面、操作步骤、配置项、规则与反馈
> 交付阶段：Phase 1（表单/列表 + 基础拖拽 + 属性面板），Phase 2（仪表盘 + 物料市场 + 主题定制）

---

## 1. 模块概述

### 1.1 是什么

页面设计器把「模型」变成「可用页面」：选模型 → 自动生成默认表单/列表 → 拖拽物料、配属性、绑数据完成定制 → 发布即用。设计器与运行时**共享同一渲染核心**，保证所见即所得。

核心体验目标：**零代码产出 80% 的中后台页面**；剩余 20% 用 L2 脚本与自定义物料逃生（§10）。

### 1.2 服务角色

| 角色 | 在本模块做什么 |
|---|---|
| 低代码开发者 | 拖拽搭建页面、配联动、绑动作 |
| 业务分析师 | 微调生成的默认页面（改标签/顺序/布局） |
| 使用者 | 只接触运行时渲染结果 |

### 1.3 入口与页面层级

- 入口：应用工作台 → 左侧导航「页面」→ 页面列表
- 页面层级：页面列表 →（点「设计」）→ 设计器画布（全屏工作区）

## 2. 页面与操作明细

### 2.1 页面列表页

**界面**：页面卡片/表格（名称/类型/路径/状态/更新时间）+「新建页面」。

| 操作 | 触发 | 系统行为 |
|---|---|---|
| 新建页面 | 「新建页面」向导 | 三步：①选页面类型（表单/列表/详情/仪表盘）②选模型（详情/仪表盘可不选）③选择「空白页 / 由模型生成默认页」 |
| 设计 | 卡片「设计」按钮 | 打开设计器（先获取编辑锁，见 §08） |
| 预览 | 卡片「预览」 | 新窗口打开预览沙箱（P1 只读真实数据） |
| 复制 | 「···」→ 复制 | 拷贝 PageSchema 生成副本，节点 id 重新生成 |
| 删除 | 「···」→ 删除 | 二次确认；页面从导航消失；被菜单引用时提示 |
| 路径设置 | 「···」→ 设置 | 修改访问路径（唯一性校验）与页面标题 |

**模型驱动的默认生成（选择"由模型生成"时）**：

- 表单页：按字段顺序单列布局；required 标红；enum→下拉、relation→远程搜索、richtext→富文本；
- 列表页：取前 8 个 indexed/基础字段为列；自动生成搜索栏（text→输入框、enum→下拉、date→日期范围）；内置操作列（详情/编辑/删除）；
- **生成是一次性快照**：之后模型变更不自动改页面；设计器持续做「模型差异检测」——引用字段被删/改名时，画布对应节点标黄警示，提示处理。

### 2.2 设计器工作区（三栏布局）

```
┌─────────┬───────────────────────┬─────────────┐
│ 物料面板 │        画布（中）        │  属性面板(右) │
│ (左)    │  DeviceFrame 可切换     │  按选中节点   │
│ 分组折叠 │  PC / 移动宽度          │  propsSchema │
│ 搜索过滤 │  页面大纲树(左下角)      │  自动生成     │
└─────────┴───────────────────────┴─────────────┘
顶部工具栏：撤销/重做 · 预览 · 保存 · 发布 · 缩放 · 视图切换
```

#### 2.2.1 拖拽与布局

- 从物料面板拖组件到画布：落点高亮 + 容器 hover 边框；支持容器嵌套（Card/Tabs/FormContainer）；
- 选中组件：显示锚点与快捷操作浮层（上移/下移/复制/删除）；
- 大纲树（左下）：组件树点击定位、拖拽调整层级；
- 撤销/重做：50 步快照栈；
- 仅支持**流式/栅格布局**，不做自由画布绝对定位。

#### 2.2.2 属性面板（选中节点后）

属性面板由该物料的 `propsSchema` **自动生成表单**（"用低代码编辑低代码"）：

| 配置分组 | 内容 |
|---|---|
| 基础属性 | 标签、占位符、禁用、尺寸等（按物料定义） |
| 数据绑定 | 字段绑定下拉（仅当前模型 ACTIVE 字段，DELETED 置灰提示） |
| 联动规则 | 显隐/禁用/必填/选项过滤表达式（L1） |
| 事件/动作 | 按钮类物料配置动作绑定（§2.4） |
| 高级 | 自定义样式类名（P2 主题变量级）、自定义 ID |

#### 2.2.3 字段联动配置

| 联动类型 | 配置方式 | 示例 |
|---|---|---|
| 显示/隐藏 | `visibleWhen` 表达式 | `{{ status === 'draft' }}` |
| 禁用 | `disabledWhen` | `{{ locked === true }}` |
| 必填切换 | `requiredWhen` | `{{ amount > 5000 }}` |
| 选项过滤 | 数据源过滤表达式 | 部门变化过滤人员选择器选项 |
| 值联动 | 字段变更钩子（L2）或计算字段 | 单价×数量=金额 |

- 表达式**设计态实时求值预览**：错误立即标红含原因，无法保存；
- 运行时按依赖字段建立**字段级订阅**，变化只重渲染受影响组件；
- 插入 L2 脚本时给出提示文案：「优先使用表达式，可维护性更高」。

### 2.3 表单设计器专项

- 分组：Group 容器折叠/展开；
- 分步表单：StepBar 容器，每步可独立校验；
- 提交模式：整体提交 / 分步暂存（配置项）；
- 表单校验时机：失焦校验 + 提交时全量校验。

### 2.4 动作绑定（按钮类物料）

选中按钮 → 属性面板「动作」区 → 添加动作（支持串行编排，成功推进/失败中断）：

| 动作类型 | 配置项 | 说明 |
|---|---|---|
| SUBMIT 提交 | 成功后行为（刷新列表/跳转/toast） | 校验→create/update→回调 |
| TRIGGER_FLOW 触发流程 | 选流程定义 + 业务主键来源 | 提交后发起流程实例 |
| CALL_API 调用 API | 选已注册 API + 参数映射 | 继承当前用户权限 |
| OPEN_PAGE 打开页面 | 目标页面 + 参数传递 | query 传参 |
| DELETE 删除记录 | 确认弹窗文案可配 | 逻辑删除 |
| CUSTOM_SCRIPT 自定义脚本 | L2 脚本编辑器（§10） | 有测试台 |

### 2.5 列表设计器专项

**列配置区**（选中 Table 物料后属性面板展开）：

- 列的显示/排序/宽度/固定（左/右）；
- 列格式化：日期格式、金额千分位、枚举标签色、自定义映射表；
- 操作列自定义：增删内置按钮（详情/编辑/删除），可挂动作；
- 筛选器与列**解耦配置**：筛选区独立拖拽物料；
- 批量操作：选中行后浮现批量按钮（批量删除/批量调流程/导出）；
- 导出：当前筛选条件导出 Excel（异步任务，上限 10 万行，见 §05）。

### 2.6 仪表盘设计器（P2）

- 布局：24 列栅格拖拽，卡片容器内嵌图表物料；
- 图表数据源三选一：模型聚合（分组/计数/求和）/ 模型列表（前 100 条）/ 静态 JSON；
- 图表联动：点击扇区 → 跳转列表页带筛选参数；
- 明确不做自由 BI：无自定义 SQL、无跨模型 join 图表。

### 2.7 物料库

**P1 基础物料**：Input、TextArea、InputNumber、Select、DatePicker、Switch、Radio、Checkbox、Upload、RichEditor、UserPicker、DeptPicker、Table、FormContainer、Card、Tabs。

**P2 业务物料**（差异化竞争力）：AddressPicker（省市区联动）、OrgTreeSelector、FilePreview、AmountInput（千分位/大写金额）、ApprovalTimeline（审批时间线）。

**自定义物料接入**（P2）：遵循 `MaterialMeta` 协议（componentName/category/propsSchema/component/runtime），走编译轨道（§06），通过租户物料市场上架（§08）。

### 2.8 页面路由与菜单

- 页面路径全局唯一，支持层级（`/order/list`）；
- 菜单管理入口在应用「导航配置」（§07），此处仅提示"该页面是否已在菜单"；
- 未加入菜单的页面仍可直链访问（受页面权限控制）。

### 2.9 移动端适配策略（P1 保底 / P2 完整）

对应顶层 PRD §3.2「响应式/多端适配」与 §4「移动端 H5」基线要求，分期兑现：

**P1（保底可用——不承诺"适配"，承诺"能用"）**：

- 运行时页面在移动端浏览器可正常使用：栅格自动堆叠为单列、表格降级为卡片列表（前 5 列 + 展开详情）、表单控件渲染原生触屏友好的交互（日期/选择器调用系统能力）；
- 设计器**不支持移动端编辑**（PC Only），设计器内提供「移动预览」切换按钮（375px 视口模拟）；
- 不做断点级布局编排——即用户不能为移动端单独调整组件顺序/隐藏某组件。

**P2（完整适配）**：

- 断点级配置：物料属性面板增加「PC / 移动」两套布局配置开关，组件级显隐与顺序可按断点差异化；
- 移动端专属交互物料：拍照上传、扫码输入、定位采集；
- 响应式规则由渲染引擎统一执行（见前端技术文档 02 渲染管线），设计器只做配置不自带执行逻辑。

**性能预算（对应顶层 PRD §4）**：

| 指标 | 要求 |
|---|---|
| 设计器操作响应（拖拽落点/选中/属性面板打开） | < 200ms（P95） |
| 画布 200 节点内任意操作 | < 100ms（R7 细化） |
| 移动端表单首屏（3G 快速档） | < 3s |

### 2.10 主题与品牌（P2）

- 应用级主题配置：Logo、主色、登录页背景、CSS 变量集；
- 仅开放变量级定制，不支持自定义 CSS 注入。

## 3. 业务规则汇总

| # | 规则 | 来源 |
|---|---|---|
| R1 | 默认页面生成为一次性快照，模型变更不自动改页面，但有差异检测提示 | §2.1 |
| R2 | 字段绑定下拉仅列 ACTIVE 字段，DELETED 置灰 | 决策 §6.1 |
| R3 | 表达式设计态报错阻断保存；运行时异常降级为空不白屏 | §06 |
| R4 | 联动优先级：能用 L1 表达式就不用 L2 脚本（设计器提示） | §10 |
| R5 | 仅流式/栅格布局，不做自由画布 | 边界 |
| R6 | 撤销重做 50 步；自动保存草稿 30s 节流（§08） | §08 |
| R7 | 画布 200 节点内操作响应 < 100ms；属性面板打开 < 200ms | 性能 |

## 4. 权限点

| 权限点 | 说明 |
|---|---|
| 页面查看 | 运行时访问该页面 |
| 页面设计 | 进入设计器编辑（需先获编辑锁） |
| 页面删除/路径设置 | 应用管理员或开发者 |

## 5. 验收标准

- [ ] 任选模型一键生成表单页 + 列表页，发布后可增查改删
- [ ] 拖拽调整布局、改属性、撤销重做全链路可用，且设计器预览与运行时渲染一致
- [ ] `visibleWhen` 表达式设计态报错无法保存；运行时按依赖正确联动且无整页重渲染
- [ ] 列表筛选器（输入/下拉/日期范围）组合查询正确，分页正常
- [ ] 按钮绑定 TRIGGER_FLOW 提交后能发起流程并携带业务主键
- [ ] **设计器操作响应 < 200ms（P95）**；画布 200 节点拖拽落点 < 100ms（顶层 PRD §4 指标落地）
- [ ] P1：核心页面（表单/列表）在 375px 移动浏览器可用（栅格堆叠 + 表格转卡片），设计器「移动预览」切换正常
- [ ] P2：断点级显隐配置发布后，PC 与移动端渲染差异化生效
- [ ] 模型删除字段后，引用它的页面节点标黄警示，存量页面正常渲染不报错
- [ ] 100 字段表单首屏渲染 < 1s；1 万行列表虚拟滚动不掉帧

## 6. 边界与不做的事

- 自由画布（绝对定位）布局
- 页面版本 diff 可视化对比（P3，先有快照）
- 多语言页面文案（P3）
- 自定义 CSS 注入（P2 仅变量级）
- 移动端设计器编辑（设计器 PC Only，移动端仅运行时消费 + P2 断点配置）
- SSR/SEO（中后台无需求）
