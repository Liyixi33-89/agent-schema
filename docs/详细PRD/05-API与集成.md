# 详细PRD 05 · API 与集成

> 上游文档：《PRD-低代码平台产品规划》v0.2 §3.5；L4 连接器决策见 §6.4/§7
> 本文定位：功能操作级 PRD——入口、界面、操作步骤、配置项、规则与反馈
> 交付阶段：Phase 1（自动 CRUD API），Phase 2（API Key/开放平台/Webhook/预置连接器/L4），Phase 3（GraphQL）

---

## 1. 模块概述

### 1.1 是什么

三层开放能力：

1. **对内自动 API**：模型保存即得标准 CRUD 接口，前端 request-sdk 与流程动作节点共用；
2. **对外开放平台**：外部系统凭 API Key 消费租户数据（配额/审计/文档自助）；
3. **集成通道**：出站（预置连接器 + L4 自定义连接器）与入站（Webhook 订阅）。

原则：**自动 API 与开放 API 是同一套引擎的两种鉴权入口**——内部走用户 JWT + 权限链，外部走 API Key + 授权范围，避免两套实现行为漂移。

### 1.2 服务角色

| 角色 | 在本模块做什么 |
|---|---|
| 低代码开发者 | 页面/流程中直接消费自动 API，无需感知 |
| 集成开发者 | 建 API Key、配 Webhook、配连接器 |
| 外部系统 | 凭 Key 调用开放 API；接收 Webhook 事件 |

### 1.3 入口

- 自动 API：无独立界面（模型保存后即存在）；调试入口在「API 文档」页
- 开放平台/连接器：应用工作台 →「集成」菜单

## 2. 页面与操作明细

### 2.1 自动 CRUD API

**统一协议**（内部 request-sdk 与外部消费者共用）：

```
GET    /api/open/v1/data/{modelKey}?filter=&sort=&page=&size=&fields=
GET    /api/open/v1/data/{modelKey}/{id}
POST   /api/open/v1/data/{modelKey}
PUT    /api/open/v1/data/{modelKey}/{id}
DELETE /api/open/v1/data/{modelKey}/{id}          # 逻辑删除
POST   /api/open/v1/data/{modelKey}/batch-upsert  # 按 key 字段 upsert
POST   /api/open/v1/data/{modelKey}/query         # 复杂过滤条件树
```

**filter 条件树**（复杂条件走 /query）：

```json
{ "op": "AND",
  "conds": [
    { "field": "status", "op": "eq", "value": "approved" },
    { "field": "amount", "op": "between", "value": [1000, 50000] },
    { "op": "OR", "conds": [ { "field": "dept", "op": "in", "value": ["d1","d2"] } ] }
  ] }
```

**使用规则（对用户的透明约束）**：

- 操作符白名单：eq/ne/in/nin/like/between/gt/gte/lt/lte/isnull；
- DELETED 字段直接 400（不给数据线索）；
- 未建索引且行数 > 50 万的字段排序/过滤：响应带慢查询提示头（引导设索引）；
- 深分页 `page×size > 100000` 拒绝，建议游标接口（P2 提供 cursor 参数）；
- **权限继承**：内部调用继承用户功能+数据+字段权限；外部按 Key 授权范围 + 可配数据范围规则。

### 2.2 API 文档页

- 按元数据**动态生成 OpenAPI 3.1 文档**（字段类型映射 JSON Schema、枚举值、示例）；
- 模型变更后文档自动更新（缓存失效 10s 内）；
- 内置调试台（Swagger UI 风格）：可用测试 Key 调用（仅限测试租户数据）。

### 2.3 API Key 管理（P2）

**界面**：Key 列表（名称/状态/授权范围/近 30 天调用量/创建时间）+「创建 Key」。

| 操作 | 触发 | 系统行为 |
|---|---|---|
| 创建 Key | 「创建 Key」 | 填名称/备注/有效期/IP 白名单 → 勾选「模型 × 动作」授权矩阵 → 生成 `sk_{tenant}_{random}`，**明文只展示一次** |
| 吊销 | 「吊销」 | 二次确认；立即失效；历史调用记录保留 |
| 编辑范围 | 「编辑」 | 改授权矩阵/IP 白名单，即时生效 |

**配额与限流**：

- 默认 10 次/秒、10000 次/日（可购加量包，计入护栏档位）；
- 超限返回 429 + `Retry-After`；未授权模型 403 且**不计配额**；
- 每次调用记录 KeyId/路径/耗时/状态/结果条数，按字段维度聚合供影响面分析消费。

### 2.4 Webhook 事件订阅（P2，出站）

**界面**：订阅列表 +「新建订阅」向导：选事件类型 → 选模型 → 填目标 URL + 请求头模板 → 配重试策略 → 测试投递 → 保存。

| 设计点 | 方案 |
|---|---|
| 事件类型 | `record.created / updated / deleted`、`flow.started / finished` |
| 投递语义 | At-least-once；消费者按 `eventId` 幂等 |
| 重试 | 5 次指数退避（1m/5m/30m/2h/6h），最终失败进死信 + 控制台告警 |
| 签名 | HMAC-SHA256 头，时间戳防重放（5 分钟窗口） |
| 载荷 | 变更前后快照（脱敏）+ 操作者 + eventId |
| 安全 | 出站 URL 过 SSRF 校验（内网禁入，同 L4 策略） |

### 2.5 预置连接器（P2）

覆盖：企微/飞书/钉钉（组织同步、消息推送、待办卡片）、短信、邮件、OSS 直传。

**配置界面**：连接器卡片 →「配置授权」→ 填租户级凭证（如企微 corpid+secret，加密存储）→ 测试连通 → 保存。

- 连接器动作以「步骤」形式被流程编排引用：发消息动作 = 选应用 + 消息模板 + 接收人规则；
- 模板变量用 L1 表达式引用流程上下文（`{{ record.amount }}`）；
- 每个连接器实现统一 SPI，新增连接器不改流程引擎。

### 2.6 L4 自定义 HTTP 连接器（P2）

**创建向导**（六步）：基本信息 → 鉴权（NONE/BASIC/BEARER/HMAC/OAuth2）→ 定义动作（方法/路径/参数）→ 字段映射（响应 JSONPath → 平台字段，**可视化连线**）→ 测试调用 → 保存。

**运行时能力**：

- 调用日志：最近 500 次请求（密钥无条件脱敏）、耗时、状态；
- 失败一键重放（非幂等方法需勾选「我确认可重放」）；
- 域名白名单：提交后**管理员审批**（防 SSRF/钓鱼域），企业版可自助。

**工程红线**（详见 §10）：DNS 解析后校验真实 IP、禁 30x 跳内网、内网 CIDR 全黑名单、密钥 KMS 加密只存 secretRef。

### 2.7 批量导入导出（P2）

**导入**：Excel/CSV 上传 → 字段列映射（自动匹配列名，映射模板可保存）→ 预校验（错误行**内联标红**）→ 选择「仅导入合法行 / 下载错误行修正」→ 异步任务执行 → 结果报告。

**导出**：列表页「导出」→ 按当前筛选条件 → 异步生成 → 站内通知 + 下载中心取件；上限 10 万行，超出引导分批。

**权限**：导入需写权限、导出需读权限，分开校验；**导出受字段权限约束**（不可见字段不出现在文件）；导出行为全量审计。

## 3. 业务规则汇总

| # | 规则 | 来源 |
|---|---|---|
| R1 | 自动 API 与开放 API 同引擎双鉴权入口，行为不漂移 | §1.1 |
| R2 | Key 明文只展示一次，库存哈希 | §2.3 |
| R3 | 未授权调用 403 不计配额；超限 429 + Retry-After | §2.3 |
| R4 | Webhook at-least-once + eventId 幂等 + 签名防重放 | §2.4 |
| R5 | 所有出站 URL 过 SSRF 校验 | §2.4/§2.6 |
| R6 | 开放 API 字段消费聚合进影响面分析（API_CONSUMER 口径） | §01 |
| R7 | 导出受字段权限约束且全量审计 | §2.7 |

## 5. 验收标准

- [ ] 模型保存后 10 秒内（缓存失效）自动 API 可查询新字段
- [ ] filter 条件树嵌套 AND/OR 查询结果与列表页同等筛选一致
- [ ] Key 未授权模型返回 403 且不扣配额；超限返回 429 + Retry-After
- [ ] OpenAPI 文档随模型变更自动更新；调试台可用测试 Key 完成一次调用
- [ ] Webhook 收到带签名事件；重放 5 分钟前时间戳的请求被拒绝
- [ ] 导入 1 万行含错误行：合法行入库、错误行可下载修正文件、报告准确
- [ ] 导出文件不含无权限字段列，导出行为出现在审计日志
