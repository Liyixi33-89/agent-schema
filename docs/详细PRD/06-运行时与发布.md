# 详细PRD 06 · 运行时与发布

> 上游文档：《PRD-低代码平台产品规划》v0.2 §3.6；决策 §6.2（双轨渲染）、§6.3（纯 SaaS + 私有化预留）
> 本文定位：功能操作级 PRD——入口、界面、操作步骤、配置项、规则与反馈
> 交付阶段：Phase 1（动态渲染 + 单环境发布 + 回滚），Phase 2（多环境 + 编译轨道 + 预览沙箱）

---

## 1. 模块概述

### 1.1 是什么

运行时引擎回答三个问题：

1. **渲染**：已发布的 PageSchema 如何变成用户看到的页面？（双轨：动态解析 / 编译产物）
2. **发布**：设计态改动如何安全到达线上？（环境隔离 + 版本 + 回滚）
3. **性能**：大 Schema、大数据量、慢网络下如何保持体验？

核心不变量：**设计器预览与线上运行共用同一渲染核心**，差异只在 DesignMode 包装层——这是"所见即所得"的工程保证。

### 1.2 服务角色

| 角色 | 触点 |
|---|---|
| 使用者 | 运行时应用（登录→导航→页面），完全无感本模块存在 |
| 低代码开发者 | 「发布」「预览」「回滚」按钮背后的机制 |
| 应用管理员 | 多环境审批、发布记录查看 |

## 2. 功能与操作明细

### 2.1 双轨渲染（机制说明）

```
PageSchema JSON
   │
   ├─ 节点 componentName → 物料注册表
   │      ├─ runtime='dynamic'  → 同步组件 / lazy(() => import(chunk))   【轨道 A】
   │      └─ runtime='compiled' → import(/* artifactUrl */ ) 加载编译产物 【轨道 B】
   │
   └─ props 中的 {{expr}} → 表达式引擎求值 + 字段级依赖订阅
```

**轨道 A（动态解析，默认）**——覆盖默认组件与物料协议组件：

- 物料按页面所需 componentName **精准分包懒加载**（Suspense 骨架屏），首屏只拉当前页面物料；
- Schema 更新即时生效：运行时请求带 `If-None-Match`（Schema 版本号），304 走缓存、200 拉新版——**发布不发版**；
- 未知 componentName 渲染占位组件 + 上报（禁止白屏）。

**轨道 B（编译产物，自定义代码）**——覆盖客户手写源码：

- 设计态 Monaco 保存 → 服务端编译（Node Worker esbuild）→ 产物 `artifact-{contentHash}.js` 上传对象存储 → PageSchema 记录 `artifactHash`；
- 运行时 `import()` 加载产物（必须导出 `render(ctx)` / `default` 组件约定）；
- **编译失败不覆盖线上**：artifactHash 不更新，线上继续跑上一版，设计器展示错误行号；
- 产物 URL 长缓存（contentHash 不可变）；Schema 记录 hash 保证可审计"线上跑的是哪版代码"；
- CSP 禁 `unsafe-eval`：一切客户代码必须是预编译产物，禁止运行时字符串编译。

**判据（走哪条轨道）**：不是「内置 vs 自定义」，而是「**能否用 propsSchema 描述**」——能用的一律走 A，需要写逻辑/直接操作 DOM 的才走 B。

### 2.2 应用发布（用户操作）

**P1（单环境）**：

```
设计器保存草稿 → 顶部「发布」按钮 → 弹窗确认变更清单（页面/模型/代码变更摘要）
   → 生成发布快照 → 运行时 ETag 失效 → 用户下次进入页面即新版
```

- **草稿与发布态分离**：设计器改 draft，运行时读 published；未发布改动不影响线上；
- 发布记录：版本号、操作人、变更页面清单；
- **回滚**：发布记录页选历史版本一键回滚（P1 即支持——快照便宜）。

**P2（多环境）**：

- 开发/测试/生产三环境，数据与 Schema 全隔离；
- 发布流向单向：开发 →（提审）测试 →（审批）生产（生产审批默认开，详见 §08）；
- 环境间 Schema 传输带**依赖完整性校验**：引用的模型/物料/连接器是否存在，缺失清单式提示。

### 2.3 运行时容器（使用者视角）

- **路由**：登录后拉「应用路由表」（页面 path → pageId + 菜单树），懒加载 Schema JSON；
- **鉴权**：路由守卫校验页面可见性；按钮级权限点集控制动作放行；
- **布局**：应用导航壳（侧边菜单/顶栏/租户品牌），页面内容区渲染 Schema；
- **异常兜底**：401 跳登录、403 提示、5xx 重试页、未知组件占位——任何异常不白屏；
- **缓存**：Schema 按 pageId+version 缓存（内存 + HTTP）；权限清单 5 分钟缓存 + 服务端失效推送。

### 2.4 预览沙箱（P2）

- 设计器「预览」打开独立预览链接——**鉴权走短时一次性预览凭证交换**（点击预览 → 服务端签发 5 分钟有效、单次使用、可撤销的 preview grant，链接只含 grantId 不含 token；首次访问用 grant 换取会话级短时凭证，URL 栏永不出现长期 token）+ sandbox 标记；
- 预览权限：仅应用开发者及以上可发起；预览会话继承发起人权限但**默认只读**（写操作拦截）；
- 预览访问记审计（who/when/应用/页面）；凭证泄露可由发起人一键吊销全部预览链接；
- 数据源可切换：真实数据（只读模式）/ mock 数据（按模型字段类型生成随机数据）；
- 预览态写操作默认拦截（toast 提示预览态），可显式开启「允许真实提交」（红色警示）。

### 2.5 性能与容灾要求（对用户的可感知承诺）

| 指标 | 要求 |
|---|---|
| 页面首屏（Schema 拉取 + 渲染） | < 1.5s（P50），< 3s（P95） |
| 列表 1 万行虚拟滚动 | 不掉帧 |
| 表单 100 字段提交校验 | < 300ms |
| 慢查询保护 | 单查询超 3s 熔断提示 + 慢查询日志 |
| Schema 变更后 | 不做全量重渲染（字段级订阅） |
| 编译产物加载失败 | 三次重试后节点级错误占位，不影响整页 |

## 5. 验收标准

- [ ] 同一 PageSchema 在设计器预览与运行时渲染一致（抽查 10 个物料）
- [ ] 发布后刷新页面即新版，无需发版/清 CDN；回滚同理
- [ ] 自定义代码编译失败时线上仍运行上一版，设计器可见错误详情
- [ ] 断网/接口 500/未知组件三种异常下页面均不白屏（占位 + 上报）
- [ ] 表达式引用字段被删除后，旧页面降级为空而非崩溃（字段类型不可变，不存在类型变更场景）
- [ ] P2：测试环境发布到生产缺依赖时被完整性校验拦截并列出缺失项

## 6. 边界与不做的事

- SSR/SEO（中后台无需求）
- 运行时多主题热切换（登录时确定，切换需重登）
- 离线 PWA
- 自定义代码 SourceMap 线上还原（P3，先做错误堆栈压缩规则提示）
