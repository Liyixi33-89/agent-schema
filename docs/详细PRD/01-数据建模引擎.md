# 详细PRD 01 · 数据建模引擎

> 上游文档：《PRD-低代码平台产品规划》v0.2 §3.1（含 §3.1.1 变更策略、§3.1.2 影响面）、决策 §6.1
> 本文定位：面向产品/设计/前端的**功能操作级 PRD**——入口、界面、操作步骤、配置项、规则与反馈
> 交付阶段：Phase 1（建模/字段/关系/校验/变更基础版），Phase 2（版本回滚/导入导出/体检修复）

---

## 1. 模块概述

### 1.1 是什么

数据建模引擎是平台的**第一大主体模块**：用户在此定义"业务对象长什么样"（如：客户、订单、报销单），平台据此自动生成表单、列表、API，流程引擎引用其数据结构。**建模质量决定平台一切衍生能力的上限。**

### 1.2 服务角色

| 角色 | 在本模块做什么 |
|---|---|
| 业务分析师 | 画 ER 图表达业务对象与关系，快速出原型 |
| 低代码开发者 | 精细配置字段校验、默认值、关系、计算字段 |
| 应用管理员 | 审批高风险变更、查看模型变更历史 |

### 1.3 入口与信息架构

- 入口：应用工作台 → 左侧导航「数据模型」→ 模型列表页
- 页面层级：模型列表 →（点模型卡片）→ 模型详情（字段/关系/数据三个 Tab）

## 2. 页面与操作明细

### 2.1 模型列表页

**界面**：顶部工具栏 + 模型卡片流（图标、名称、key、字段数、最近更新时间/人）+ 右下角「新建模型」按钮。

| 操作 | 触发方式 | 系统行为 |
|---|---|---|
| 新建模型 | 点「新建模型」 | 弹窗：名称（必填）/ key（自动生成可改，小写字母+数字）/ 图标 / 描述；确认后创建并进入详情页 |
| 搜索 | 顶部搜索框 | 按 name/key 实时过滤；支持拼音首字母 |
| 排序 | 列头点击 | 按更新时间/名称排序，记忆用户选择 |
| 打开模型 | 点卡片任意位置 | 进入模型详情「字段」Tab |
| 查看数据 | 卡片「数据」按钮 | 跳转该模型的数据列表页（需记录查看权限） |
| 删除模型 | 卡片「···」→ 删除 | 走 §2.7 删除流程（逻辑删除 + 影响面确认） |

### 2.2 字段 Tab（默认）

**界面**：字段表格（字段名/key/类型/必填/索引/状态/操作）+ 右上「添加字段」按钮；支持拖拽调整字段顺序。

#### 2.2.1 添加字段

点「添加字段」→ 右侧抽屉表单：

| 配置项 | 说明 | 规则 |
|---|---|---|
| 字段标签 | 用户可见名 | 必填，同模型内不强制唯一（提示建议唯一） |
| 字段 key | 存储键 | 自动按拼音/翻译生成，可改；**创建后不可改** |
| 字段类型 | 12 种（见下表） | 创建后类型不可改；需要换类型 = 新建字段 + 人工迁移 |
| 必填 | 开关 | 必填性改严**不回溯存量**（仅新数据校验） |
| 默认值 | 按类型给控件 | 支持固定值 / 当前时间 / 当前用户 |
| 校验规则 | 多条叠加 | 必填/长度/正则/数值范围/唯一/自定义表达式 |
| 枚举选项 | enum 类型专属 | 见 §2.2.2 枚举管理 |
| 唯一索引 | 开关 | 开启后异步生成提升列，构建期不阻塞查询 |
| 帮助文本 | 输入框 | 表单/详情页字段下方灰字提示 |

**字段类型清单（12 种）**：

| 类型 | 表单默认控件 | 特有配置 |
|---|---|---|
| 文本 text | 单行输入框 | 最大长度、正则 |
| 多行文本 textarea | 多行输入框 | 最大长度 |
| 数字 number | 数字输入框 | 小数位数、范围 min/max |
| 日期 date / 日期时间 datetime | 日期(时间)选择器 | 可选范围 |
| 单选枚举 enum | 下拉选择 | 选项管理 |
| 布尔 boolean | 开关 | — |
| 文件 file | 文件上传 | 数量上限、类型、单文件大小 |
| 富文本 richtext | 富文本编辑器 | — |
| 关联 relation | 选择器（见 §2.4） | 目标模型、基数、级联策略 |
| 地理位置 geo | 地图选点 | 默认地图中心 |
| 人员 user / 部门 dept | 组织架构选择器 | 单选/多选 |
| 计算字段 computed | 只读展示 | 公式（L1 表达式）+ 取值时机 |

#### 2.2.2 枚举选项管理（enum 类型专属）

界面：选项列表（拖拽排序）+「新增选项」。每个选项含：值（value）/ 标签（label）/ 颜色标记（列表页标签色）。

- **新增选项**：直接生效；存量数据不受影响。
- **改标签**：允许（value 不变）；列表按新标签展示。
- **删除选项**：仅标记「已废弃」，不做数据清洗——存量数据保留旧值，展示时带"已废弃"灰色标签；新数据不可再选该值。
- 选项值被引用提示：删除前提示该值在存量数据中的出现次数。

#### 2.2.3 计算字段（公式）

- 配置界面：公式编辑器（输入 `{{ }}` 表达式）+ 依赖字段列表（自动解析）+ 取值时机选择。
- 取值时机二选一：
  - **读取时计算**（默认）：不落库，每次读取求值——适合低频/实时性要求高的字段；
  - **持久化**：依赖字段写入时同步重算落库——适合列表筛选/排序的高频字段。
- 保存校验：公式语法错误、引用了不存在/已删除字段、循环依赖 → 标红阻断保存（循环依赖给出环路径）。

### 2.3 关系 Tab

**界面**：关系列表（关系名/类型/目标模型/级联策略/操作）+「新建关系」。

#### 操作流程（以"订单 → 客户"为例）

1. 点「新建关系」→ 抽屉：选关系类型（1:1 / 1:n / n:n）；
2. 选目标模型（下拉，列出应用内所有 ACTIVE 模型 + 已授权的跨应用引用模型）；
3. 命名关系字段（如「所属客户」）——1:n 在本模型生成一个 relation 字段；
4. 选级联策略：禁删 / 置空 / 级联逻辑删除；
5. 确认后：本模型字段列表出现该关系字段；表单里自动生成对应选择器。

**规则**：

- 变更关系类型（如 1:n → n:n）需影响面确认，**平台不自动改写存量关联数据**，由用户自行校验后用转换工具（P2）处理；
- 关系字段展示控件按基数决定：1 → 单选下拉（远程搜索）；n → 多选穿梭框；
- 目标模型删除时：提示所有引用它的关系字段清单。

### 2.4 ER 画布视图（P1 简版 / P2 完整）

- 字段 Tab 右上「画布视图」切换：以节点图展示本应用模型与关系连线，拖拽排布；
- 画布上可直接：新建模型（空白处双击）、拖线建立关系（从一个模型拖到另一个弹出关系配置抽屉）；
- 画布仅做**表达与编辑入口**，复杂配置仍回抽屉表单完成；
- P2 支持跨应用模型引用的虚线展示。

### 2.5 数据 Tab（模型数据预览）

- 列表展示该模型数据（分页 20/页），列 = ACTIVE 字段前 8 个；
- 行操作：查看详情 / 编辑 / 逻辑删除；
- 权限：需「记录查看」权限；行级数据权限在此同样生效；
- 用途定位：**建模过程的数据验证**，完整业务列表页在页面设计器配置（§02）；
- **大数据量承诺（顶层 PRD §4 指标落地）**：单模型百万级记录时，数据 Tab 与列表页分页查询 < 1s（P95）——依赖「提升列」机制：高频筛选/排序字段标记索引后异步生成物理列，查询走列索引而非 JSONB 全扫；未标记索引的字段筛选在百万级数据下可能超时，此时界面提示「建议将该字段标记为索引」并附一键跳转。

### 2.6 Schema 变更流程（对应 PRD §3.1.1 定稿）

所有"保存"动作统一走以下流程：

```
用户编辑字段/关系 → 点保存
   │
   ├─ 前端本地 diff（新增/修改/删除清单）
   ▼
调用影响面分析接口 → 弹出影响面清单弹窗
   │
   ├─ 🟢 低风险（新增字段/改标签/加枚举值）：展示即可，一键确认
   ├─ 🟡 中风险（删字段/改必填）：勾选"我已了解影响"才能提交
   └─ 🔴 高风险（删被引用字段/删模型）：输入模型名确认 + 审计 + 通知应用 Owner
   ▼
提交变更 → 元数据落库（删除仅置 DELETED 标识，物理列与数据永久保留）
   → 生成版本快照（P2）→ 异步提升列任务（如有索引变更）→ 缓存失效广播
```

**前端隐藏规则（删除字段后的即时表现）**：

| 场景 | 表现 |
|---|---|
| 列表页 | 该列消失 |
| 表单 | 不渲染该控件 |
| 筛选器 | 不出现该条件 |
| 新页面/新流程引用 | 选择器中置灰不可选，给出提示 |
| 存量页面/流程引用 | 降级为隐藏，不报错阻断 |
| API 响应 | 默认剔除该键（管理员可带 `includeDeletedFields=true` 查历史，记审计） |

### 2.7 删除模型

- 入口：模型卡片「···」→ 删除；
- 弹窗展示：影响面清单（引用它的页面/流程/关系字段/数据量）；
- 确认方式：输入模型名（高风险交互）；
- 结果：模型标记 DELETED，列表隐藏（可在「已删除」筛选器找回查看），表与数据永久保留；
- 恢复：版本回滚（P2）或管理员在已删除列表恢复。

### 2.8 版本历史与回滚（P2）

- 入口：模型详情右上「···」→ 版本历史；
- 界面：时间线列表（版本号/时间/操作人/diff 摘要），点开看该版本字段定义详情；
- 回滚：以历史快照为新版本提交（DELETED 字段恢复 ACTIVE），需确认 + 审计；**只恢复定义，不动数据**（数据本就没删）。

### 2.9 数据体检与修复工具（P2）

- 入口：模型详情「···」→ 数据体检；
- 体检：异步任务按字段类型扫描不兼容记录（如旧值非数字），输出清单；
- 修复操作三选一：批量置空 / 批量替换指定值 / 按映射表转换；每次修复生成任务 + 执行前后统计快照；
- **平台不自动发起修复**，全部人工触发。

### 2.10 Schema 导入导出（P2）

- 导出：模型定义 JSON 导出（不含数据）；
- 导入：上传 JSON / Excel（模板下载）→ 字段映射预览 → 冲突检测（key 重复）→ 确认导入；导入失败行给出明细。

## 3. 业务规则汇总

| # | 规则 | 来源 |
|---|---|---|
| R1 | 字段 key 创建后不可修改 | 防引用失效 |
| R2 | 删除字段/模型仅逻辑删除，物理列与数据永久保留 | 决策 §6.1 |
| R3 | 必填性收紧不回溯校验存量数据 | 决策 §6.1 |
| R4 | 类型变更仅对新写入生效；存量不兼容值展示 `--` | 决策 §6.1 |
| R5 | 枚举删除选项仅置废弃标记，不清洗数据 | §2.2.2 |
| R6 | 关系类型变更不自动改写存量关联数据 | 决策 §6.1 |
| R7 | 计算字段循环依赖保存被阻断 | §2.2.3 |
| R8 | 所有变更保存前强制影响面分析 | 决策 §6.1 |
| R9 | 变更操作全量进审计日志 | §04 |
| R10 | 撤销分两层：编辑器内 Ctrl+Z（未保存）/ 版本回滚（已保存） | 决策 §6.1 |

## 5. 验收标准

- [ ] 新建模型并添加全部 12 类字段可保存，字段 key 自动生成且创建后不可改
- [ ] 删除字段后：列表列消失、表单不渲染、筛选器不出现、API 响应剔除该键、数据库列仍在
- [ ] 删除被 ≥3 个页面引用的字段时，必须输入模型名才能保存，且应用 Owner 收到通知
- [ ] 类型变更后：新写入按新类型校验；旧值列表展示 `--`
- [ ] 枚举删除选项后：存量数据带"已废弃"标签，新数据不可选
- [ ] 计算字段循环依赖保存被阻断并给出环路径
- [ ] 字段标记索引后异步生成提升列，失败可重试且期间查询不阻塞
- [ ] **百万级数据分页查询 < 1s（P95）**：预置 100 万行测试数据，索引字段筛选/排序/分页组合查询达标（顶层 PRD §4 指标落地）
- [ ] 所有变更在审计日志可查（谁/何时/diff）
- [ ] P2：版本回滚后字段定义恢复，页面重新展示该字段，数据未变化

## 6. 边界与不做的事

- 物理 DROP COLUMN（永不提供；运维工具除外且需审批）
- 自动数据迁移/类型转换脚本（存量数据永远由用户决定怎么处理）
- 字段级加密存储（脱敏展示归 §04，加密存储 P3）
- 多数据源虚拟模型（P3）
- 模型继承/Mixin（P2 后评估）
