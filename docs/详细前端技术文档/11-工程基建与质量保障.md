## 1. 职责边界

| 负责 | 不负责 |
|---|---|

| 构建/产物策略（设计器与运行时隔离） | 后端 CI（后端文档 10） |

## 2. 包依赖拓扑（单向，CI 强制）

```
schema-protocol          ← 零依赖（纯类型 + 表达式引擎，禁止依赖 React）
   ▲          ▲
   │          │
schema-renderer ──▶ component-materials（仅类型依赖 MaterialMeta）
   ▲    ▲
   │    └──────────────▶ schema-form
   │                         ▲
flow-designer / data-model-designer / designer(app)
   │
runtime(app) / admin-console(app)

共享底座：request-sdk / auth-sdk / usage-tracker / shared-ui（互不依赖，仅被 apps 与上层 packages 引用）

规则：
  apps 不得直接依赖另一个 app 的内部模块（跨 app 复用必须下沉 package）
  所有跨包 import 忱须走包名（禁止相对路径跨包引用——lint 规则）
  schema-protocol 依赖数恒为 0（依赖检查器 CI 断言）
```

## 3. 构建与产物策略

```
三产物线（Turborepo pipeline）：
  designer      → 部署 /designer/*（含全部设计态代码）
  runtime       → 部署 /app/*（tree-shake 掉 design 代码，CI 断言）
  admin-console → 部署 /admin/*

关键策略：
  Vite define 双入口（schema-renderer designer.ts / runtime.ts）
  公共 chunk 策略：react/vendor 单独分包；物料按 §05 分片
  产物相对 publicPath + /config.json 运行时配置（私有化红线）
  CI bundle 断言：runtime 产物不含 'DesignModeWrapper' 等设计器符号；
                 gzip 体积预算（runtime 首屏 < 300KB，超限失败）
```

## 4. 测试金字塔

| 层 | 工具 | 覆盖目标 | 门禁 |
|---|---|---|---|
| 单元 | Vitest | 协议层/表达式引擎/hooks/命令系统（各文档 §测试要求） | 行覆盖 ≥ 80%（protocol/renderer 90%） |
| 组件 | RTL + Storybook | 物料受控契约、属性面板交互 | 关键交互用例全绿 |
| 契约 | Vitest（CI 专属） | zod↔Java 校验规则 diff、OpenAPI 类型 diff、functions.json/redlines.json 双端 diff | diff 非空即失败 |
| E2E | Playwright | 关键链路：建模→生成页面→保存→发布→运行时渲染→提交数据 | PR 必跑 |
| 性能基准 | Vitest bench（CI 节点） | 100 字段表单渲染、200 节点画布操作、表达式求值 | 超预算 ±20% 失败 |

## 5. CI 门禁清单（PR 合并硬性项）

## 6. 性能监控（线上采样）

- Web Vitals（LCP/INP/CLS）采样上报（usage-tracker 通道，观测类事件）；
- 关键体验打点：设计器画布操作延迟、页面 Schema 加载时长、轨道 B 产物加载失败率；
- 性能预算红线（PRD/详细 PRD 02 §3）：画布操作 < 100ms、100 字段表单首屏 < 1s、1 万行列表不掉帧——CI 基准 + 线上采样双重执行。

## 7. 工程规范落地

- ESLint 关键自定义规则：跨包相对路径禁止、zustand set 调用点约束（设计器）、禁止直接 `fetch`（统一 request-sdk）；
- commitlint + PR 模板（关联需求文档编号）；
- Storybook：物料文档与属性面板文档同源（propsSchema 即文档输入）；
- 版本策略：packages 内部变更不影响对外 API 时 patch；schema-protocol 任何变更（表达式白名单/类型）必须 minor 起步 + 双端同步发版。

## 8. 单元测试硬性要求

- [ ] 依赖拓扑：违规引用（protocol 依赖 React / 跨包相对路径）被 lint 拦截（规则单测）
- [ ] bundle 断言：人为引入设计器符号到 runtime 入口时 CI 失败
- [ ] 契约 diff：篡改 functions.json 后 CI 报差异
- [ ] 性能基准：基准用例在预算内通过（防基准本身腐化的元测试）
