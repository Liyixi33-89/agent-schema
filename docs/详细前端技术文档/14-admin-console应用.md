# 详细前端技术文档 14 · admin-console 应用（apps/admin-console）

> 上游：《技术方案-前端(React).md》v0.2 §2（Monorepo 三应用之一）；详细 PRD 09（运营与计量）、05 §2.4（API Key 管理台）、04（成员管理后台触点）；后端文档 06 §A（Key 体系）、09 §A（用量/配额）、13 §A.5（租户管理）
> 本文定位：**实现级技术设计**——租户侧管理后台与平台侧运营后台的页面架构、路由域划分、鉴权分层
> 应用：`apps/admin-console`（与 designer/runtime 平级的第三个 L4 组合根）
> 红线：admin-console 是**普通 AntD 应用**（非低代码渲染）——管理界面低代码化是 P3 反射性需求，一期用代码写

---

## 1. 职责边界与双域划分

admin-console 承载**两类角色差异极大的后台**，路由域物理分开：

| 路由域 | 角色 | 页面 | 权限特征 |
|---|---|---|---|
| `/console/**`（租户侧） | 租户管理员 | 用量与配额、席位明细、成员/组织管理、应用管理、模板中心、连接器凭证、通知偏好 | 租户内 RBAC（`perms` 快照） |
| `/admin/**`（平台侧） | 平台运营 | 租户清单/停服/档位、配额饱和度榜、空闲租户榜、异常告警、开放平台全局监控、模板上架 | 平台级角色 + `@TenantIgnore` 后端通道 |

- 两域同一构建产物、不同路由前缀与守卫策略——平台运营人员通常不进租户域（登录后按角色跳转默认域）；
- **不负责**：设计器（designer）、运行时（runtime）的任何页面——三应用互不引用代码，共享逻辑全部下沉 packages（洋葱模型 L4 判据：删掉它能被另一个宿主替代）。

## 2. 技术架构

```
apps/admin-console/
├── bootstrap/               # 组合根：AppConfig + 路由 + 守卫装配
├── console/                 # 租户域（页面模块）
│   ├── usage/               # 用量与配额（§3）
│   ├── members/             # 成员/席位（消费后端 03 §A.3 + 13 §A.2）
│   ├── apps/                # 应用管理（消费后端 13 §A.1-A.4——工作台同款接口）
│   ├── api-keys/            # Key 管理台（§4）
│   ├── connectors/          # 连接器配置向导（消费后端 07 §A，复用设计器向导组件）
│   └── templates/           # 模板中心（消费后端 13 §A.4）
└── admin/                   # 平台域（页面模块）
    ├── tenants/             # 租户管理（消费后端 13 §A.5）
    ├── metrics/             # 商业化报表：饱和度榜/空闲榜/漏斗（§5）
    └── alerts/              # 异常告警面板（消费通知死信/防薅报表）
```

- 复用 packages：request-sdk（hooks 体系）、auth-sdk（登录态）、shared-ui（布局壳/表格/表单组件，文档 16FE）、主题引擎（租户域跟随应用品牌，平台域固定平台蓝——文档 13FE §1）；
- **不依赖** schema-renderer/component-materials——没有低代码渲染需求，bundle 与设计器解耦（依赖断言：admin-console 不 import L2 引擎层任何包）。

## 3. 租户域核心页：用量与配额（PRD 09 §2.2）

```
页面结构：
  指标卡片区（6 张）：席位(x/上限)、流程执行(月)、AI 额度、存储、API 调用、编译次数
    → GET /api/metering/usage/summary（后端 09 §A.2）一次性返回
    → quotaStatus 三态着色：OK 绿 / SOFT 橙（附宽限天数）/ HARD 红（附升级按钮）
  席位明细表：成员 × 30 天活跃状态 × 清理不活跃席位操作
    → 活跃状态列渲染：绿点（当日活跃）/灰点（30 天内）/警示（曾活跃现不活跃）
    → 「清理席位」= 移除该成员开发者角色（PUT members 接口，后端 13 §A.2）——操作确认弹层
       明示「次日计量生效」（后端席位口径，文档 09 §4）
  趋势图：近 90 天曲线（6 指标切换 Tab）
    → GET /api/metering/usage?metric=&from=&to= → ECharts LineChart（复用 ChartKit，文档 12FE §2）
```

- 数据展示**只读后端口径**：前端不计算配额百分比以外的任何派生指标（口径漂移防线，后端 09 §A.2 前端对接要点）；
- `QUOTA_EXCEEDED` 弹层（升级引导）在本应用复用同一组件（文档 07FE §4 约定）。

## 4. 租户域核心页：API Key 管理台（PRD 05 §2.4）

```
页面结构：
  Key 列表：名称/掩码（sk_...4位尾码）/scope 摘要/最近调用/操作（后端 06 §A Key 体系）
  创建弹层（PRD 05 §2.4 五步）：基本信息 → scope 勾选（模型×动作树） → 数据范围 → 限流档位 → 创建
  创建成功页：明文 Key 仅展示一次 + 复制按钮 + 「关闭后不可再查看」警示条
    （复制走 navigator.clipboard；不缓存明文；关闭弹层即丢弃——后端 key_hash 不可逆）
```

- scope 勾选树：模型清单 × 动作（read/create/update/delete）复选树，数据源为应用模型清单接口；
- 调试面板（P2）：Key 管理台内嵌「调试请求」抽屉——选模型/动作/参数 → 实发 `/api/open/v1/*` 请求展示响应（帮客户在对接前自检 scope 是否配对）。

## 5. 平台域核心页：商业化报表（PRD 09 §2.4）

```
配额饱和度榜：饱和度 ≥80% 租户清单，排序 = 饱和度 × 席位数
  → 数据源：GET /api/admin/metrics/saturation（平台侧聚合接口，后端 09 §A.2 扩展）
  → 行内操作：「生成跟进任务」标记 CSM 队列（写内部任务表，P2）
空闲租户榜：付费且席位活跃 <20% → 流失预警
指标异常告警：环比突增 >300% 清单（消费后端防薅检测结果，09 §8）
行为漏斗：建模 → 生成页面 → 发布 → 活跃使用 四级衰减（北极星过程指标）
  → 前端只做漏斗图渲染（ChartKit），口径计算全部服务端
```

- 平台域页面**不开放给租户管理员**（路由守卫按平台角色硬拦，403 页与租户域 403 同款样式）；
- 平台域数据接口全部走后端 `@TenantIgnore` 白名单通道——每次调用记审计（后端 13 §A.5 协议），前端不缓存平台报表数据（staleTime 0）。

## 6. 路由与守卫

```
守卫双层（与运行时容器同模式，文档 06FE §4）：
  域级守卫：/admin/** 需平台角色（perms 含 platform:* 点位），否则重定向 /console
  页面级守卫：各页面对应权限点（用量查看/成员管理/Key管理等，PRD 09 §4）

登录跳转策略：
  登录成功 → 按角色判定默认域：平台运营 → /admin/metrics；租户管理员 → /console/usage
  auth-sdk 权限快照判定（perms 含 platform 前缀点位即平台角色）
```

## 7. 与另两个应用的边界契约

| 共享能力 | 归属 | admin-console 消费方式 |
|---|---|---|
| 登录态/权限 | auth-sdk | 同款（token 2h 刷新、快照失效广播） |
| 请求层 | request-sdk | 同款 hooks；平台域接口不注入 X-Tenant-Id（后端平台通道） |
| 布局壳/表格/表单组件 | shared-ui | 直接复用（文档 16FE 组件清单） |
| 图表 | ChartKit | 复用（趋势图/漏斗/饱和度榜） |
| 连接器向导 | designer 内组件抽包 | P2 时随连接器配置需求抽到 shared-ui（先由设计器独占） |
| 工作台应用管理 | — | **不复用 designer**：应用管理页面在 console 域重写（设计器是建模工具不是管理后台） |

## 8. 单元测试硬性要求

- [ ] 域守卫：租户管理员访问 /admin/** 被重定向；无权限页面 403 占位
- [ ] 明文 Key：创建弹层关闭后内存无明文残留（垃圾回收断言/无日志输出）；复制功能正常
- [ ] 用量页：quotaStatus 三态着色正确；席位清理确认弹层文案含「次日生效」
- [ ] 平台通道：/admin 域请求不带 X-Tenant-Id（请求拦截器断言）；报表数据零缓存
- [ ] 依赖断言：admin-console 不 import schema-renderer/component-materials（dependency-cruiser 规则）
- [ ] 口径只读：用量页组件无任何配额派生计算（除百分比格式化外的计算代码扫描为零）
