## 五、预检当前的可用形态

已实现并验证（PR #80 待合）：

```
# 生产：admin 声明为预期拒绝（若确认它不该有业务数据权限）
deploy.py --target prod --expected-no-scope admin

# 验收：accept_user 声明为预期拒绝（暂不配 SELF 时）
deploy.py --target accept --datascope-strict --expected-no-scope accept_user
```

这样两个库都能发布，同时**不扩大任何权限**。
等确认模型清单后，再按「专用角色 + 按模型授权」正式配置。
