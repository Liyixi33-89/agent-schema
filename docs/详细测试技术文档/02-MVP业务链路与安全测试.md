## 1. 主链路 E2E：建号到回滚（闭环门核心）

**层级：L-E2E（Playwright + 真实后端栈）**；**门禁：M15 闭环门 + G1**；**数据：种子公司 + 数据工厂**。

### 1.1 黄金链路用例（单条用例贯穿 MVP 全部核心模块）

**TC-E2E-01 建号→改密→建模→页面→保存→预览→发布→运行→回滚**

```
前置：测试租户 T-A 存在，操作者为 tenant-admin
步骤：
 1. 管理员创建成员（一次性初始密码）→ 成员首登被 PASSWORD_CHANGE_REQUIRED 拦截
    → 强制改密 → 响应内联签发新 token 对 → 用新 token 访问受保护接口成功（03BE §A.3.1）
 2. 成员（开发者角色）建模型「订单」：12 种字段类型全覆盖 + 索引提升 1 个字段（PRD 01）
 3. 生成 CRUD 页面（PRD 02）→ 拖拽修改布局 → 保存草稿（乐观锁 version+1）
 4. 插入 3 条种子数据 → 表单按 Schema 校验拦截 1 条非法提交（前端校验 + 后端二次校验双断言）
 5. 预览模式打开页面 → 正常渲染交互 → 默认写请求被服务端拒绝、正式数据不变；开启 allowRealWrite 的独立授权路径另测真实写入与审计（不假设 P1 已有隔离预览库）
 6. 发布 v1 → 运行时访问 `/apps/{app}/pages/{page}` 渲染 v1 → page_release_version 落一行（04BE §A.6）
 7. 修改页面再发布 v2 → 运行时渲染 v2
 8. 回滚到 v1 → 运行时恢复 v1 渲染（逐组件比对）→ 回滚产生新 releaseVersion，内容与 v1 一致；原 v1/v2 快照不变，回滚动作有审计（不假设快照含 status=rollback）
预期：步骤 1-8 全部通过；运行时渲染与设计器预览在种子公司上视觉一致（快照比对）
证据：Playwright HTML 报告 + 录屏 EV-M15-E2E-01
```

**TC-E2E-02 流程数据登记闭环**（P1 画布只读 + 登记，PRD 03）：发起登记类流程 → 填表 → 提交 → 状态可见——**不含审批执行（P2）**，断言边界即「尝试审批操作被拒且提示分期」。

**TC-E2E-03 工作台导航闭环**（M11.4）：应用 CRUD → 配置导航 → 运行时导航壳 `GET /api/apps/{id}/nav` 服务端过滤（无权限菜单不出现于响应体——**而非前端隐藏**，断言响应 JSON）。

### 1.2 链路回归包（冒烟子集，进 ci）

TC-E2E-01 的步骤 5-7（预览→发布→运行）抽出为 15 分钟冒烟版——每次 push 在 CI 跑，防止渲染/发布链路回归。

## 2. 租户隔离与权限测试（安全基线主体）

**层级：L-Integration（Testcontainers）+ L-E2E 断言贯穿**；**门禁：M15 + G2**；**职责：后端开发强制编写（10BE §7.1——每个新增查询 Service 附越权用例，缺失不合并）**。

### 2.1 隔离不变量（精确断言，非通过率）

| 用例 | 操作 | 不变量断言 |
|---|---|---|
| TC-ISO-01 伪造租户头 | 租户 T-B 用户带 `X-Tenant-Id: T-A` 请求 | 返回 403 TENANT_MISMATCH，不执行业务查询或写入、不泄露任何租户数据；记录安全审计（03BE §4/§A.4） |
| TC-ISO-02 跨租户资源 ID | T-B 用户直接引用 T-A 的 modelId/pageId/fileId 发起 CRUD | 404（非 403——不泄露资源存在性）+ 审计记录 |
| TC-ISO-03 行级权限 | 部门 A 成员查全量列表 | 仅返回部门 A 行；SQL 层断言（捕获生成 SQL 含行级条件）而非仅结果集 |
| TC-ISO-04 字段级权限（P2） | 无权限成员读记录 | 敏感字段在响应中缺位（结构层移除）且不参与序列化——**断言响应 JSON 无该键** |
| TC-ISO-05 MyBatis 拦截器全覆盖 | 对全部含租户列的表跑查询矩阵 | 每张表有拦截测试登记（防漏配 tenant_id 的表裸奔）——表清单为断言资产 |
| TC-ISO-06 权限判定链 | 覆盖 RBAC 继承/互斥角色/委托全分支 | 判定链单测全分支覆盖（03BE §3.2） |

### 2.2 会话与凭证生命周期

| 用例 | 场景 | 断言 |
|---|---|---|
| TC-SESS-01 强制改密拦截 | 初始密码首登 | 受保护接口全拒（403 + PASSWORD_CHANGE_REQUIRED），仅放行名单内接口（改密/登出）可访问 |
| TC-SESS-02 改密后旧 token 失效 | 改密成功 | 旧 access token 立即 401（服务端失效，非仅前端丢弃）；新 token 内联签发可用 |
| TC-SESS-03 多标签登出同步 | 标签页 A 登出 | 标签页 B 通过 BroadcastChannel 收到事件并清理——**降级路径**：不支持 BroadcastChannel 时轮询/me 或 storage 事件兜底，不允许依赖标签页隔离的 sessionStorage 单打独斗 |
| TC-SESS-04 预览凭证单次有效 | grant 5min 窗口 | 同一 grant 二次交换被拒；过期 grant 被拒（04BE §A.7） |
| TC-SESS-05 预览凭证吊销闭环 | 吊销 grant | 在途 previewSessionId 的下一次请求 401 即时失效；WebSocket/长轮询通道同步断开 |
| TC-SESS-06 凭证跨租户不可用 | T-B 用户拿 T-A 的预览 grant | 404 + 审计（绑定约束：grant 与租户/用户/应用三元组绑定） |
| TC-SESS-07 注销冷静期与恢复工单 | 租户注销 → 冷静期内撤销 | 撤销后数据完整可用；冷静期结束执行清除 → 数据物理删除/匿名化 + 注销证明生成；恢复工单状态机全迁移路径覆盖（13BE §A.4.1：申请→确认→回灌中→成功/失败，每个状态有合法入口出口） |

## 3. L2 Worker 隔离测试（G7 门禁，一票否决）

**层级：L-E2E——必须真实浏览器（08FE §3 红线：jsdom 模拟不了 Worker CSP 与 terminate）**；**门禁：M15 编写 + G7 验收；未通过则 L2 功能整体关闭上线（feature flag），无「客户自担」豁免**。

| 用例 | 验证点 | 断言 |
|---|---|---|
| TC-L2-01 环境隔离能力面 | 脚本访问 window/document | undefined（环境断言）；**不做全局对象不可达断言**（WorkerGlobalScope 必然存在——08FE 定版） |
| TC-L2-02 token 不进 Worker | 消息桥全量断言 | Worker 消息流中无凭证字段；`api.call` 由主线程代理，响应不含 token 回传 |
| TC-L2-03 死循环硬中断 | `while(true){}` | 10s 后 worker.terminate() 生效、主线程恢复、页面其余功能完好（核心验收项——AbortSignal 做不到） |
| TC-L2-04 网络出口三层兜底 | Worker 内发起白名单外 fetch | ①红线扫描编译期拦截；②Worker 脚本响应头 CSP `connect-src 'none'` 浏览器阻断（**断言浏览器报 CSP violation 而非请求成功**）；③网关鉴权拒（无凭证 401）——三层各自独立可测 |
| TC-L2-05 钩子超时 | onBeforeSubmit 超时 | 超时后钩子链放行/阻断按钩子类型定版语义执行 + 上报 |
| TC-L2-06 测试台保真 | 脚本测试台执行结果与运行时一致 | 同一脚本双环境执行结果 deepEqual（08FE §6） |
| TC-L2-07 feature flag 开关 | G7 未过时 | 平台侧一键关闭 L2 功能，含 L2 的页面降级渲染（visibleWhen 等基础表达式不受影响——L1/L2 分层断言） |

## 4. 发布与运行时安全

| 用例 | 场景 | 断言 |
|---|---|---|
| TC-PUB-01 发布快照完整性 | 发布 v1 | page_release_version 不可变全量存 Schema；断言快照字段与设计器保存版 deepEqual |
| TC-PUB-02 回滚后前向兼容 | 回滚 v1 后再发布 v3 | schemaVersion 迁移链正向可用（旧版本快照经迁移管线渲染） |
| TC-PUB-03 运行时不可变 | 运行时访问期间并发编辑 | 运行时始终渲染已发布版本，不受草稿编辑影响（版本引用而非指针） |
| TC-PUB-04 编译产物完整性 | P1 编译链路 | esbuild 单文件产物 hash 回写一致；产物篡改（改一字节）→ hash 校验失败拒载 |
| TC-PUB-05 高危确认绑定 | 删除应用等高危操作 | `confirmValue` 字段与操作目标绑定（输错目标名拒执行）；确认 token 四元组（用户/操作/目标/时效）一次有效 |

## 5. 攻防六类用例（PRD 10 §5 → M15 验收）

| # | 类别 | 代表用例 | 预期 |
|---|---|---|---|
| A1 | 注入不执行 | 数据字段提交 `{{7*7}}`、`<script>`、表达式字符串注入到 Schema | 存储为纯文本；渲染转义；表达式按字面量处理不执行 |
| A2 | 跨站不改数据 | XSS payload 经富文本/文件名/错误信息路径 | tiptap JSON 存储 + DOMPurify 双端清洗生效；CSP 阻断内联执行 |
| A3 | CSP 阻断 | 设计器/运行时/产物域三态策略下注入违规模块加载 | 浏览器阻断 + Report-Only 期上报清零误报（G2 前置） |
| A4 | 伪造租户全拒 | TC-ISO-01/02 全矩阵 + JWT 篡改（改 claim 重签） | 签名校验拒绝；claim 与头不一致返回 403 TENANT_MISMATCH + 审计 |
| A5 | 死循环可终止 | TC-L2-03 + L3 沙箱同类（P3，本期仅登记） | 硬中断生效 |
| A6 | 未授权嵌入被拒 | 外域 iframe 嵌入运行时页面 | CSP frame-ancestors 拒绝；网关 Origin 校验拒（CSRF 三道兜底之一） |

**执行记录要求**：每类用例执行留证据物（EV-M15-ATTACK-*），G2 验收引用——渗透测试摘要由安全负责人出具。

## 7. 数据正确性专项（引擎层回归）

| 用例 | 场景 | 断言 |
|---|---|---|
| TC-DATA-01 CRUD 全类型 | 12 种字段类型读写往返 | 写入→查询→deepEqual（JSONB 精度、时区、布尔、数组往返无损） |
| TC-DATA-02 乐观锁并发 | 两会话并发改同一记录 | 后提交者 409 乐观锁冲突，不覆盖；前端提示刷新重试（心跳机制按 08PRD） |
| TC-DATA-03 提升列一致性 | JSONB 字段标记索引后 | GENERATED ALWAYS AS ... STORED 列由 PostgreSQL 自动计算，查询值与 JSONB 源值一致（无应用层双写）；去标记后物理列软失效（永不 DROP COLUMN 承诺验证） |
| TC-DATA-04 软删与引用 | 删除被页面引用的字段 | 字段软删 DELETED；页面引用处设计态 FieldMissingError（01 篇 C-REF-01 联动）；存量数据保留 |
| TC-DATA-05 聚合协议执行 | AggregateRequest 五类聚合 | 双端聚合结果一致（measures/group/timeBucket 语义——评审稿 §7 #2 回归） |

## 8. 门禁挂接与验收标准（本模块自身）

## 9. 边界与不做的事

- 不做渗透测试的完整替代——攻防六类是自验基线，正式渗透测试在 L-GA（G8）前外聘执行；
- 不做 DDoS/流量型攻防（属基础设施层，云侧防护，PRD 11 单区域部署期由云厂商能力承接）；
- L3 脚本沙箱（P3）本篇仅登记 A5 占位，不展开用例——L4 连接器攻防属 P2 后续补篇；
- 不测浏览器兼容性矩阵（MVP 期 Chrome/Edge 双内核，Firefox/Safari 留 L-GA 后）。
