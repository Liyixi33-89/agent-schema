## 1. 容量与性能压测（M16 独立容量验收证据）

> 门禁编号以 PRD 11 §3 为准：G5 是人工支持，不是性能门禁。容量压测按 PRD 11 §2.4 与 M16 单独附报告；本文新增 CPU/连接池水位、长任务与恢复 30s 等数值是待评审观察目标，不得冒充 PRD 硬阈值。

**层级：L-Perf（k6/Gatling，预发布环境）**；**门禁：M16 + G5**；**环境要求：与生产同构规格、同区域、独立数据库实例**。

### 1.1 压测模型（L-Pilot 基线 = PRD 11 §2.4 减半）

| 维度 | L-Pilot 基线（M16 执行） | L-GA 基线（G8 前执行，本篇登记） |
|---|---|---|
| 并发用户 | **250 并发**在线（依赖图 M16 定版） | 500 并发 |
| 场景配比 | 混合：70% 读 / 20% 写 / 10% 发布 | 同 |
| P95 响应 | < 1.5s | < 1.5s |
| 错误率 | < 0.5% | < 0.5% |
| 单模型容量 | 100 万行 CRUD 达标（P95 < 1s，PRD 01 §5） | 同 + 容量规划结论 |
| 资源水位 | CPU < 70%、内存无持续增长（泄漏检测）、连接池 < 80% | 同 |

### 1.2 压测场景脚本

| 脚本 | 场景 | 关键断言（精确不变量） |
|---|---|---|
| PERF-01 混合读写发布 | 250 VU 按 70/20/10 配比循环：Schema 拉取 / 数据 CRUD / 保存草稿+发布（发布按低频节流模拟真实） | P95 < 1.5s 全接口；错误率 < 0.5%（**分接口统计**，禁止整体平均掩盖单接口劣化） |
| PERF-02 容量数据集 | 预置单模型 100 万行（数据工厂生成，索引提升字段含高频查询） | 高频查询 P95 < 1s；分页深翻页无性能悬崖（offset 翻页策略验证） |
| PERF-03 表达式负载 | 含 visibleWhen/计算属性/聚合的种子页面高频渲染 | 前端渲染不阻塞（Playwright trace 采样主线程长任务 < 200ms）；后端聚合接口 P95 达标 |
| PERF-04 并发发布冲突 | 多人并发编辑同一应用（乐观锁路径） | 409 比例与重试成功率统计；无数据覆盖（最终一致性不变量） |
| PERF-05 压测中恢复 | PERF-01 稳态运行中注入一次应用实例重启 | 恢复后 30s 内错误率回落基线；无级联雪崩（熔断/重试有效性） |

### 1.3 压测报告模板（G5 证据物）

`EV-M16-PERF-*` 必含：环境规格表（机型/节点数/DB 规格）、场景与 VU 曲线、分接口 P95/P99 表、错误分类统计、资源水位截图、与上次基线的对比结论、瓶颈分析与容量规划建议。**无对比基线的报告视为无效**（首次除外，首次即建立基线）。

## 2. 备份与恢复演练（G3 证据，不可全自动化但流程脚本化）

**层级：L-DR**；**门禁：M16 + G3；此后每季度常态（PRD 11 §2.2）**。

### 2.1 演练脚本化步骤

```
DR-01 全量恢复演练：
 1. 触发一次手动备份（数据库 + 对象存储 + 配置三层，PRD 11 §2.2 一致性要求）
 2. 拉取最近备份到隔离恢复环境（脚本执行，记录取回耗时）
 3. 完整恢复（记录恢复耗时 = RTO 实测值）
 4. 数据抽样校验：随机抽 1000 行逐字段比对 + 行数全表比对 + Schema 版本表完整性
 5. 应用连通性验证：恢复环境跑 TC-E2E-01 冒烟子集（预览→发布→运行）
 6. 出报告归档，演练环境销毁
```

### 2.2 不变量断言（G3 验收线）

| 断言 | 阈值 |
|---|---|
| 数据抽样一致率 | ≥ 99.9%（PRD 11 §3 G3） |
| 实测 RTO | ≤ 4h（PRD 11 §5 自身验收）；L-Pilot 同样须达标，不得仅记录实测值后放行 |
| RPO | 备份频率定义内的数据损失上限实测确认 |
| 三层一致性 | 数据库/对象存储/配置恢复后相互引用完整（文件 ID 可解析、Schema 引用的物料可加载） |

### 2.3 单租户恢复路径（登记，P2 完整验证）

从备份重建单租户数据到独立验证环境 → 客户确认 → 回灌——恢复工单状态机测试已在 02 篇 TC-SESS-07 覆盖状态层；数据层端到端演练属 P2 范围（13BE §2.2），本篇仅登记占位。

## 3. 故障注入与可观测验收（G4 证据）

**层级：L-DR + L-Integration；门禁：M16 + G4**。

| 用例 | 注入方式 | 断言 |
|---|---|---|
| TC-FT-01 DB 连接池耗尽 | 模拟连接泄漏至池满 | 熔断生效不雪崩；恢复后自愈；告警触发（连接池水位 > 80%） |
| TC-FT-02 慢查询 | 注入无索引大查询 | 慢查询大盘可见（10BE §4 可观测）；P0 级告警路由正确 |
| TC-FT-03 下游超时 | 元数据服务延迟 > 阈值 | 超时降级（渲染走缓存 Schema）+ 告警 |
| TC-FT-04 实例崩溃 | kill 应用节点 | 网关摘除节点；用户请求无感（多实例）；P0 告警触达值班通道 |
| TC-FT-05 告警触达演练 | TC-FT-01/02/04 触发的告警 | **P0/P1 分级路由正确**（P0 电话/短信 + IM，P1 仅 IM）；触达时延记录（目标 P0 < 5min）；值班确认回执闭环 |
| TC-FT-06 错误率大盘 | 全部注入期间 | 错误率/慢查询/资源三大盘数据与注入时间线吻合（可观测数据可信性断言） |

**租户级健康页**（14FE §5a 消费 10BE §4.1 契约）：注入期间健康页状态正确流转（healthy → degraded → recovering），租户管理员视角可见维护公告（13BE §A.4 契约消费验证）。

## 4. 升级与回滚演练（平台侧）

| 用例 | 场景 | 断言 |
|---|---|---|
| TC-UP-01 平滑升级 | 应用层滚动升级（新旧版本并存） | 兼容矩阵流程走通（PRD 11 §2.5）；Schema 缓存一致性不受影响（10BE §2 元数据缓存失效机制验证） |

## 7. 边界与不做的事

- 不做异地多活/多区域容灾演练（L-Enterprise 按客户触发，PRD 11 §7）；
- 压测不模拟真实地理分布与公网抖动（单区域部署，预发布环境同区域内网压测——网络层差异留 L-GA 后云侧评估）；
- 混沌工程平台（ChaosMesh 等）不引入——MVP 期故障注入用脚本化手段（kill/iptables/连接池配置），工具化留 L-GA；
- 不做生产环境压测——预发布环境同构规格推算容量，生产压测属 L-GA 后灰度演练。
