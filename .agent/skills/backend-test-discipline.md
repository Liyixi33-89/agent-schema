# 后端测试纪律

## 何时使用

为任何 Java 代码写测试、修复测试失败、或讨论测试范围时。测试体系总纲：`docs/详细测试技术文档/00`；契约测试：01 篇。

## 规则/经验

1. **层级归属先定位**（00 篇 §2）：领域/App Service 纯逻辑 → Unit（JUnit5 + Mockito，禁 IO）；服务域内部（DDL/JSONB/权限 SQL/迁移）→ Integration（Testcontainers）；跨端共享物 → Contract（双端执行器）。**用例只下放不上收**。
2. **集成测试真库铁律**：Testcontainers 起**真实 PostgreSQL**，**禁 H2 替代**——JSONB/提升列/行级权限 SQL/序列行为差异正是被测对象，H2 全测不出；测试容器复用（单次 CI 会话共享实例）控时长。
3. **越权用例强制**（10BE §7.1 合并硬条件）：每个新增查询 Service 附「伪造租户上下文被拦截」用例——**缺失不予合并**；隔离断言是精确不变量（404 不泄露存在性 + 审计事件落库），非「返回 403 即过」。
4. **业务用例四路径**：成功 / 业务失败（状态机不符等）/ 越权 / 必要并发路径——只测 happy path 的 Service 不算完成；状态机类逻辑全迁移路径覆盖（恢复工单/注销/凭证生命周期：每个状态合法入口出口 + 非法迁移拒绝）。
5. **测试数据**：领域测试用对象构建器（builder）+ 固定种子；集成测试数据隔离（每用例独立事务回滚或唯一租户前缀，禁测试间共享可变数据）；**禁测试代码依赖执行顺序**。
6. **契约消费回归**：错误码触发用例（C-ERR-02——每个登记码至少一条真实触发）；表达式向量 JUnit 执行器跑全量与前端零差异（M1.5 门禁）。
7. **迁移测试**：Flyway 全链在空库跑通 + 现有库升级路径跑通（禁只测全新建库）；迁移失败阻断发布（TC-UP-04）。
8. **门禁挂接**：差异编译进 quick；全量单测 + 契约执行器进 commit；Testcontainers 集成 + E2E 冒烟进 ci。**临时注释测试/skip 无登记 = 违规**（SKIP 走 00 篇 §7 表）。

## 反模式（踩过的坑）

- @SpringBootTest 全上下文起每个测试 → 反馈慢到没人跑；切片测试（@DataJpaTest/@WebMvcTest）+ 精准装配。
- Mock 掉被测行为本身（隔离测试 Mock 拦截器） → 等于没测；隔离必须真库真拦截器。
- 测试共用静态可变数据偶发互踩 → flaky 归咎「环境问题」；数据隔离是设计问题。
- 断言只查 `assertNotNull` → 断言不了行为；精确断言字段值/行数/状态。

## 验证方式

`mvn test` 全绿；Testcontainers 用例在 CI 真执行（非 skip）；越权用例清单与 Service 清单一一对照（审查清单化）。
