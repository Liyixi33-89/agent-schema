# UI 风格一致性纪律

## 何时使用

新建页面、定制样式、选择配色/间距/字号、或任何视觉决策场景。主题真源：`docs/详细前端技术文档/13-主题引擎与品牌定制.md`；响应式：15FE。

## 规则/经验

1. **产品风格定版**：企业级中后台工具——清晰、克制、高信息效率。**禁**：大面积渐变、装饰性动画、营销式大卡片、阴影堆叠炫技。动效只用于反馈（加载/成功/展开），时长 150-300ms 为默认建议而非门禁阈值；具体服从主题与模块设计，并尊重减少动效偏好。
2. **色彩唯一真源 = 主题 token**：组件色用 AntD ConfigProvider token + CSS 变量双通道（13FE §3）；**禁组件内硬编码色值**（`#1890ff`/`rgb(...)` 直接写 style 或 CSS）——语义色统一映射：primary（品牌）、success/warning/error（结果语义，全局一致不复用为装饰色）。
3. **字号/间距/圆角用尺度阶梯**：从主题变量取值（如 spacing 4/8/12/16/24），禁任意值（`margin: 13px`）；字号层级以标题/副文/正文/辅助四级为默认建议，具体沿用主题定义；密度使用主题和 AntD 支持的配置，不在单页面另造体系。
4. **页面布局模板化**：工作台/管理列表/详情/编辑表单/设计器五类页面各按既有模板（admin-page-patterns / designer-workbench-patterns）；同类页面结构必须同构——用户在页面 A 学到的位置习惯，在页面 B 必须成立。
5. **表格与表单位置约定**：查询区在上（与工具栏分离）、主操作在表格右上、行操作在行尾列、分页右下；表单标签统一左对齐（或既定全局配置）、必填标识统一、提交区统一底部右对齐或跟随既定模板。
6. **反馈状态全覆盖**：加载（骨架屏/skeleton，禁白屏转圈）、空数据（Empty + 引导动作）、错误（重试入口）、无权限（403 说明而非隐藏入口）、提交中（按钮 loading 防重复提交）。**只实现正常态的页面不算完成**。
7. **危险操作统一确认交互**：删除/发布/回滚等用统一确认组件；高危操作按契约二次确认（confirmValue 输入目标名，04BE 定版）——禁各页面自造确认样式。
8. **可访问性底线**：所有交互键盘可达、焦点可见、表单控件有 label 关联；状态表达禁纯颜色（色弱不可辨），配图标/文字。
9. **响应式遵循全局断点系统**（15FE）：窄屏降级方案提前设计，禁窄屏直接隐藏关键操作；设计器画布区最小宽度保护。

## 反模式（踩过的坑）

- 每个开发者选一种蓝 → 同页三蓝；统一走 token，品牌调整一处生效。
- 空状态画插画占半屏 → 信息效率工具类产品空态要克制（小图 + 一句引导 + 主按钮）。
- 深层组件覆写 `!important` 打补丁 → 主题体系被架空；回 token 层解决。
- 错误只弹全局 toast 无上下文 → 表单类错误内联到字段，全局 toast 只用于操作结果。

## 验证方式

grep 断言无硬编码色值/style 任意间距（白名单：主题定义文件）；页面 CR 对照模板清单；键盘走查（Tab 全程可达 + 焦点可见）。
