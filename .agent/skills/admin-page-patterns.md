# 管理页面实现模式

## 何时使用

在工作台/admin-console/设计器内实现任何中后台管理页面（成员管理、应用列表、导航配置、恢复工单、健康页等）时。

## 规则/经验

1. **列表页固定结构**（自上而下）：面包屑/页头（标题 + 页级主操作）→ 查询区（表单 collapse 可收起，字段 ≥4 时默认收起）→ 工具栏（次级批量操作 + 刷新 + 列设置）→ 表格 → 分页。数据拉取 TanStack Query + 分页参数入 URL（刷新/回退保持状态）。
2. **表格约定**：行选择列（有批量操作才显示）；操作列固定右侧行尾、超过 3 个折叠「更多」；列宽关键列固定其余弹性；长文本截断 + Tooltip 全文；空态走 Empty 组件；加载用骨架行占位保布局稳定。
3. **详情页固定结构**：页头（返回 + 标题 + 状态 Tag + 页级操作）→ 描述列表（Descriptions 组件）分组展示 → 关联子资源区（复用列表页表格组件）。状态流转类详情（恢复工单/注销）显示**状态时间线**（Steps 组件纵向），每个状态节点带时间与操作人。
4. **新建/编辑表单**：优先按任务复杂度、子表单、可用空间选择 Modal、Drawer 或独立页；7/15 个字段只是评审参考，不是强制切换阈值；编辑表单初值从服务端拉取后 `reset` 注入（禁初值闪烁）；提交中按钮 loading + 防重复；成功后关闭 + 列表失效刷新（invalidateQueries）。
5. **删除/高危操作**：统一 Popconfirm（普通删除）或 Modal 二次确认（高危，confirmValue 输入确认）；**禁浏览器原生 confirm()**。
6. **乐观锁冲突（409）标准处理**：提示「他人已修改」+ 提供刷新查看最新版选项，**禁静默覆盖提交**（依赖图 M4 定版三方对比）。
7. **权限驱动 UI**：无权限的操作按钮不渲染或禁用 + Tooltip 说明；但**服务端过滤是安全边界，前端隐藏只是体验**（导航壳契约同理）。
8. **页面路由与代码组织**：一个列表页 = 目录（`index.tsx` 列表骨架 + `columns.tsx` 列定义 + `hooks.ts` 查询逻辑 + `components/` 弹窗表单）——禁单文件塞全部。

## 反模式（踩过的坑）

- 查询条件放 URL 但分页不放 → 用户回退丢页码体验断裂；列表态全量入 URL。
- Modal 里填一半误关数据全丢 → 超过 7 字段换 Drawer/独立页，或 Modal 加关闭确认。
- 行操作直接调 API 不走列表刷新 → 数据与 UI 不一致；统一 mutation + invalidate。
- 手写分页器「更灵活」 → 与全站分页行为不一致；用 Table 自带或既定分页组件。

## 验证方式

对照本模式 CR；键盘可达走查；列表页刷新/回退状态保持验证（URL 参数完整）。
