# 设计器工作台实现模式

## 何时使用

实现/修改页面设计器、ER 建模器、流程设计器、仪表盘设计器的布局结构与交互反馈时。真源：04FE（Canvas 引擎）、10FE（ER/流程）、12FE（仪表盘）。

## 规则/经验

1. **四区固定结构**：顶部工具栏（保存/预览/发布/撤销重做/缩放）→ 左侧物料/图层区（Tab 切换）→ 中央画布（唯一可滚动区）→ 右侧属性区。**区与区职责不混**——属性设置不弹全局 Modal，预览不跳出工作台框架。
2. **画布操作统一走命令系统**（04FE §3）：一切变更 = Command 入撤销栈；**禁绕过命令直接改 Schema**（撤销断链 + 409 冲突来源不可溯）。快捷键与工具栏按钮触发同一命令实例。
3. **选中与悬停反馈规范**：悬停 = 轻量描边（1px 品牌色 30% 透明度）；选中 = 2px 描边 + 8 向锚点 + 顶部浮动工具条（删除/复制/上移下移）；多选 = 虚线框选框 + 计数角标。反馈样式全局统一（画布 CSS 类集中定义）。
4. **拖拽管线**（04FE §4）：物料面板拖出 = ghost 跟随 + 目标区高亮吸附线；落点预览指示（插入位置线）；放下才生成命令。@dnd-kit 语义化配置，禁自造 mousemove 拖拽。
5. **属性面板由 propsSchema 自动生成**（AGENTS.md §7 硬约束 5）：新增物料 = 定义 propsSchema + 注册，**禁手写属性表单**；面板分组折叠态持久化到本地偏好。
6. **图层树**：与画布选中双向同步（点树选中画布元素）；拖拽调序与画布一致走命令；隐藏/锁定状态图标化显示。
7. **保存与冲突**：保存行为与节流参数按 04FE 及对应任务规格实现，不将未经定版的 2s 固化为协议；手动保存保留明确反馈；409 冲突弹三方对比面板（本地/远端/字段级 diff）供人工裁决，**禁静默覆盖**。
8. **性能红线**：拖拽/缩放期间画布帧率优先——选中态样式用 transform/opacity（合成层），禁拖拽中触发全树重渲（valtio 字段级订阅是为此设计，禁上帝 Context 架空它）。
9. **两个建模器差异**：ER/流程用 React Flow（10FE §3 flow-kit 公共层），画布缩放平移交给 React Flow；页面设计器自研画布保持 24 列栅格（12FE 复用）。

## 反模式（踩过的坑）

- 属性面板手写表单「先跑通」 → 新增物料成本线性增长且漏校验；第一天就走 propsSchema 生成。
- 画布选中态用 React state 全树下发 → 每次选中整树重渲，10+ 节点即卡；走订阅式局部更新。
- 拖拽中每 mousemove 提交撤销命令 → 撤销栈爆炸；命令在 drop 时一次性提交。
- 预览做新页面跳转 → 上下文丢失；工作台内嵌预览态（06FE 预览凭证通道）。

## 验证方式

撤销/重做全操作覆盖测试（每类命令至少一条用例）；拖拽帧率走查（Performance 面板无长任务 >200ms）；新增物料不写属性表单代码（grep 断言）。
